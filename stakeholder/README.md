機械可読版：`stakeholder_graph.json`（ノード54・エッジ45・包含関係42）。座標・スタイルも保持し、再描画や検索ができる形にしてある。

## 関係タイプ（凡例の色・線種から復元）
- 指揮命令系統上の上下関係：黒・実線・矢印あり … 実エッジ24本
- 対等な関係でやり取り：黒・実線・矢印なし … 実エッジ9本
- 契約関係（会社間）：青 #0066CC … 実エッジ4本（請負／下請／購買／リース）
- 承認・検査・許認可：金 #D79B00・破線 … 実エッジ3本（確認申請／中間・完了検査ほか）。官公庁→現場監督の1本は金色だが矢印なし（JSONに注記済み）
- 苦情・要望：赤 #C0392B・一点鎖線 … 実エッジ1本（近隣住民・近隣事業者→現場）
（凡例用のダミーノード／エッジは is_legend_example=true で区別して残してある）

## 主な包含（グループ）関係
- 施主：担当者、責任者、各部署の担当者
- 設計者：意匠、構造、設備
- 監理者：担当者
- 協力業者：業者A
- 業者A：職長、職人A、職人B、責任者
- 官公庁：土木課 （敷地外道路の掘削）、下水道課 （上下水配管への接続）、警察 （道路許可証発行）、経済産業省（電柱・電線への接続・引き込み）、消防署 （消防検査）、労基署
- リース業者：担当者
- 工場・資機材商社・メーカー：担当者
- 凡例：上位、下位、担当者A、担当者B、当事者A、当事者B、申請・提出する側、承認・検査する側、影響を受ける側、影響を与える側
- 本社・支店：安全・環境担当、建築本部、設備本部
- 現場：現場監督、図面屋（施工図作図者）
- 現場監督：所長、課長、担当者A、担当者B
- 確認検査機関：担当者
- 近隣住民・近隣事業者：近隣住民、自治会・近隣事業者

## ゲーム側での拡張（2026-11-08追記）

- このマップ（drawio原本とグラフ）はユーザーの作成した原本のまま保持しており、**ゲーム側の都合で原本のグラフは変更していない**。ノード54・エッジ45・包含関係42という構成も原本どおり。
- ゲーム側では、このマップを土台にした「拡張」を別レイヤーとして行っている。原本では「協力業者＝業者A（職長・職人A・職人B・責任者）」という1社構成だったものを、ゲームでは工種別に展開している：躯体・鉄骨・土工・仮設足場、設備3系統（電気・衛生・空調）、エレベータ、外装（ALC・シーリング等）、内装各社（LGS・ボード、仕上げ、建具など）。これはユーザーの指摘「現場監督：協力業者＝1:1のような関係性に実質なっているので色を付けたい」を受けた拡張で、各社にパラメータを持つ職長と、その下の班（職人）を置く。
- 職長パラメータや業種ごとの傾向の正は `model/FOREMAN_CHARACTERS.md`、業者と工程の接続の正は `model/WORK_STRUCTURE_V2.md` を参照。原本側の関係タイプ（指揮命令／対等／契約／承認・検査・許認可／苦情・要望の色分け）は、ゲーム側でも関係の見せ方の基準としてそのまま使っている。
