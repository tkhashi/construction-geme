# prototypes — 試作スペース

本編統合前に、表現や方式を検証した試作スペースのコード。各試作は単一HTMLで、そのままブラウザで開ける。

| 試作 | 目的 |
|---|---|
| [3d-trial/](3d-trial/) | スクラッチ実装の3D現場ビュー。部材単位の組立表現の原型 |
| [iso25-trial/](iso25-trial/) | アイソメ2.5D現場ビューの検証試作 |
| [iso-timelapse/](iso-timelapse/) | 工事計画（ConstructionPlan）に連動するタイムラプス アイソメ図 |
| [toon-sandbox/](toon-sandbox/) | トゥーン建物の縮尺・質感テスト（実モデル3物件で大きさ感を判定するサンドボックス） |
