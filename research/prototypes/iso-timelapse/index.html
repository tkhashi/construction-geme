工事計画タイムラプス　アイソメ図

工事計画（サイドチャット生成・ConstructionPlan）に連動し、部材が計画タスクの開始〜終了の中で1つずつ所定位置に出現する様子を、等角投影（アイソメ図）でタイムラプス再生します。建物全体が一斉にせり上がる表現ではなく、Scene3Dの部材ごとの place 時刻どおりに描画します。さらに今回、部材の出現を「担い手」の動きと結びつけました：ユンボは掘る帯（掘削前線）に沿って移動し、掘削タイルはその帯を掘り終えた時点で現れます。ラフタークレーン（1基のみ）は鉄骨の実部材そのものをワイヤーで運び、本設位置の近くへ粗く下ろし、最後は建方班が横引きで最終位置へ寄せてから固定されます。作業員（誘導員・玉掛け・建方班・打設班・鉄筋/型枠/内装/設備の各班）は、進行中タスクの作業前線に沿って配置されます。タスク期間の内側での重機・人の動きは、計画データそのものではなく、期間内作業順序の想定として生成しています（詳細は下の留保欄）。さらに今回、作業員の人数を「班の人数チップ」ではなく実人数にしました：工種ごとに必要な人区を計画側テーブルから算定し（タスク人区＝1班人数×投入班数×期間）、算出した人数を個別の作業者として現場に投下します（工区分割されたタスクは工区ごとに投下）。そして全ての部材は、出現する直前に、担当作業者がその生成箇所を画面上で通過してから現れます（掘削など重機主体の部材では誘導員・合番が通過します）。現在の現場総人数は画面左上のHUDと進捗欄に常時表示します。

      データ出典と留保

      工事計画：サイドチャット「建築 工事 計画 手順 調査」で生成した ConstructionPlan（CP-1〜CP-10、計画検証 PL 12/12 PASS、難易度 normal / seed 42 / 2027-04-01 着工）。タスク数・日付・工期は計画 JSON の値そのままです。

      部材の出現：Scene3D（scene3d/1.0）の部材ごとの place / remove イベント時刻（実働日）。足場・型枠・山留め・仮囲い等は remove 時刻で消えます。部材の位置・寸法は Scene3D の実座標そのままで、外接矩形での近似描画はしていません。

      描画上の扱い：地面は仮囲いの実配置から求めた敷地外形と、建物平面（1階床スラブ）の実フットプリントで描きます。部材はデータの画家順（奥→手前）のまま1点ずつ輪郭付きで描きます。ただし外壁・サッシ・屋根・パラペットなどの外皮部材は、薄い面が躯体・デッキに塗りつぶされないよう、躯体・デッキ・内装の後に外皮レイヤーとして描きます（外皮同士は画家順を維持）。長尺の梁・配管類はスパン単位に割って表示します。杭・埋設物などの地下部材は掘削底までの表示とし、埋戻し（1階床スラブ設置）以降は描きません。内装・設備の細部は、その階の外装が閉じた後は描きません（外から見えないため）。

      重機の動き：表示は各重機が属する計画タスクの在場区間（ES〜EF、高所作業車は搬入〜搬出の期間）の中だけです。杭打ち機・高所作業車は Scene3D の重機アクターのキーフレーム（時刻・位置）を線形補間します。ユンボ・ダンプ・ラフタークレーン・ポンプ車のキーフレームは、下記「担い手連動」の作業想定から生成したものに置き換えています。ラフタークレーンは計画どおり1基のみです。重機と人はアイソメで判読できるよう、実寸より大きめに描いています（部材・建物は実寸のまま）。

      担い手連動（タスク期間内の作業想定）：工事計画が決めているのはタスクの期間（ES〜EF）と部材の本数・座標・出現時刻の集合までで、「期間の中で誰がどう動いて施工するか」は計画に含まれません。このビューでは、その期間内の作業順序を想定として新規に組み立て、部材の出現を担い手の前線と同期させています。これは計画データの改変ではなく、タスク期間の内側だけでの並べ替えと動きの付与です（タスク・ES/EF・暦日・工期・部材の本数・実座標・寸法・出現時刻の総量はすべて無変更）。分担は現場の原則どおり、クレーンは粗い位置決めまで（仮置き／搬入位置から本設位置の近くへ実部材をワイヤー吊りで運ぶ。固定寸法のダミー荷は廃止）、人は細かい横引きと施工（着地後に作業班が最終位置へ寄せ・建て込み・固定する二段構え）です。土工事では掘削タイルの帯をユンボが走行しながら掘り、タイルは掘り終えた時点で出現します（ブームは次に掘る帯を向きます）。ダンプは掘削前線とゲートを往復します。ポンプ車のブームは、その日に打つ工区の打設前線へ向けます。人力主体の部材（鉄筋・型枠・内装・設備など）は、タスク期間の中で空間的な作業前線に沿うよう出現順序を並べ替え、作業班はその前線に沿って移動します。作業員の配置は進行中タスクと前線位置から導いたもので、個人の実在の動きではありません。

      人区の算定（計画テーブル由来）：タスク人区（人日）＝ 1班人数 × 投入班数 × 期間（実働日）。1班人数は計画側テーブル model/scene_rules.json の crewByTrade（工種ごとのゲーム用既定値）、投入班数は計画の資源リンクが示す並行班数で、計画 JSON に指定のないタスクは1班（上限は計画 resources の tradePeak。1班/タスクとした場合、同工種タスクの最大同時並行数が全工種で tradePeak 以下に収まることを生成時に確認済み）。工区分割されたタスクは計画上も別タスクであり、工区ごとに班を投下します。これは計画テーブル由来の算定であり、公表歩掛（国土交通省の労務費基準等）そのものではありません（実務の考え方自体は「歩掛×数量÷期間」で必要人数を逆算する点で同じです）。画面の作業者はこの算定人数ぶんを1人ずつ描いたもので、班チップの人数表示ではありません。
