# 屋上工事の手順（2026-11-09 調査、商業施設・陸屋根）

## 全体フロー（屋根スラブ以降）
屋根スラブ・パラペット（躯体）→ 防水下地 → 立上り防水 → 平場防水 → 保護層 → 笠木 → ドレン・通水確認 → 設備基礎 → 機器据付 → 避雷・付帯金物 → 屋上完了。
「雨水が入らなくなってから内装」の原則どおり、屋上防水の完了は内装本格化の前提条件にもなる。

## 防水（アスファルト防水・保護仕上げの標準手順）
1. 下地確認・清掃：段差・レイタンス除去、平滑化。含水率が高いと施工できないので乾燥期間を確保（雨天・下地未乾燥は施工不可＝天候ゲート）。
2. プライマー塗布。
3. 立上り先行：入隅・出隅に面木・補強シート。防水層は平場からパラペット立上りへ連続させ、立上りを平場へ150mm以上張り掛ける（国交省標準仕様）。立上り端部は仕上面より150mm以上立ち上げるのが基本。
4. 平場：溶融アスファルトでルーフィングを2〜3層貼り重ねる（熱工法）。端末は金物で押さえる。
5. 保護層：保護コンクリート（伸縮目地入り）または露出仕上げ＋トップコート。保護コンを打つと防水層は見えなくなる＝隠蔽部として施工中の記録が重要。
6. 笠木：防水の後にアルミ笠木を取り付ける（下地金物→はめ込み、継手はオープンジョイントで伸縮吸収）。笠木を先に付けると防水の端末が納まらない。
7. 検査：目視・打診に加え、ドレン周りの通水/散水確認。ルーフドレンは防水前に改修用ドレン等を仕込み、配管（管工）と接続。

## 屋上の付帯工事
- 塔屋：階段・EVのオーバーラン部分。躯体で立ち上がり、外装・防水の取り合いに含まれる。
- 設備基礎：機器据付より先に施工。芯位置・外形・天端高さを管理（ずれると配管ルートと防水納まりに波及）。
- 避雷設備：高さ20m超の建物で必要。施工は建物工程に合わせて下から進む：基礎段階で接地極を埋設し基礎鉄筋と接続（埋める前に検査・写真）→躯体の鉄骨/鉄筋を引下げ導線に→屋上防水に合わせて受雷部（屋上の縁・角に沿わせる、笠木の継目を橋絡）→竣工試験（導通・接地抵抗、10Ω以下目安）。屋上機器には突針で保護角を取る。
- その他：屋上手すり・タラップ・点検口、脱気筒（押えコンの場合50〜100㎡毎）、商業施設では屋上サイン（館銘板）の基礎・建込み（クレーン動線を確保）。

## 関わる業種・重機
防水工、左官（下地・保護コン）、金属工/板金（笠木・金物）、管工（ドレン・配管）、電気工（避雷・機器）、とび（揚重）。重機は機器・材料の揚重にラフター/タワークレーン、保護コンにポンプ車＋生コン車。
