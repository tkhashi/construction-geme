# 構造推論リサーチ：用途・規模・平面から躯体を"推論"するルール

作成：2026-11-08（無料の公開情報のみで調査。課金API不使用）
目的：公開情報（外形・間取り・用途）しか分からない建物について、柱・梁・耐震要素・基礎を「それらしく一貫して」創造する生成器の推論レイヤー基礎資料。
関連：`model/BUILDING_MODEL_SCHEMA.md`、`model/USE_RULES.md`、`model/INTERIOR_MODEL_V2.md`

## 根拠の強さの凡例

| 記号 | 意味 |
|---|---|
| | 法規・告示・国の基準類に根拠がある |
| | 自治体・学会・業界団体の指針／標準仕様（推奨値を含む） |
| | 複数の実務者ソースで一致する慣行・目安（法的な裏付けはない） |
| | 単一事例・試験対策的整理・ベンダー資料など。生成器の"らしさ"には使えるが断定不可 |

注意：数値はすべて「初期検討・推論の出発点」であって構造計算の代替ではない。生成器では推論タグ（inferred）と併せて保持すること。

## 1. 構造種別の選択ロジック

### 1.1 階数・高さによる標準選択（自治体指針）

東京都『構造設計指針・同解説』（2023年4月版）表2.1「構造種別の標準」：

| 地上階数・高さ | RC造 | SRC造 | S造 | 備考 |
|---|---|---|---|---|
| 1〜6階 かつ 20m以下 | ◎標準 | ○適用可 | ○適用可 | 階高・スパン・積載荷重の大きなものは混合構造など別途検討 |
| 7階以上 または 20m超〜45m | ※要検証 | ◎標準 | ◎標準 | |
| 45m超 | ※要検証 | ※要検証 | ◎標準 | 塔状建築物はSRC造・S造を原則 |

- 同指針では RC・SRC は「耐力壁付ラーメン架構」を基本形式とする。
- RC/SRCで耐震計算ルート1の場合は偏心率を概ね0.3以下に抑える（後述§4の法基準 偏心率0.15／剛性率0.6 とは別レイヤーの推奨値）。

出典：東京都財務局『構造設計指針・同解説』2023-04（https://www.zaimu.metro.tokyo.lg.jp/documents/d/zaimu/kouzousekkeisisin-doukaisetu20230401 ）
※表の記号はPDFのテキスト抽出から復元したもの。記号対応の最終確認は原典の表組みで行うこと。

## 2. 経済スパン・柱モジュール・梁せい

### 2.1 構造種別ごとの比較（同一建物の比較設計例）

日本鉄鋼連盟（JISF）のRC造／S造比較例：

| 項目 | RC造 | S造 |
|---|---|---|
| 最大スパン | 8m | 12m |
| 柱断面 | □750×750〜□800×1000 | □400×400 |
| 大梁最大 | 1000×600 | H-700×300×12×22 |

出典：https://www.jisf.or.jp/business/tech//school/character/hikaku.html

### 2.4 商業施設：駐車モジュールが柱割りを決める

商業施設生成の最重要ルール。**駐車場が売場の直上・直下にある場合、車室寸法がそのまま柱スパンになる**。

| ルール | 根拠の強さ | 出典 |
|---|---|---|
| 車室（普通車）2.5m×5.0〜6.0m（基準 幅2.5m(2.3m)／長さ6.0m(5.0m)） | 国土交通省『駐車場設計・施工指針』 | https://www.mlit.go.jp/road/sign/kijyun/pdf/19920610tyuusyajou.pdf |
| 柱スパン ≒ 車室幅×3台分：歴史的には2.3m幅×3＝約8〜8.5mスパン、近年は2.5〜2.6m幅で **9m超** のスパンへ | 建築計画系テキスト（国立国会図書館デジタル） | https://dl.ndl.go.jp/view/prepareDownload?itemId=info:ndljp/pid/3488153&contentNo=26 |
| 身障者用車室は幅約3.5m必要 → その列だけモジュールがずれる | | 同上 |
| 柱の最小辺30cm（駐車場指針）—柱が車路・ドア開閉に干渉しない配置が前提 | | MLIT駐車場指針 |
| 海外ガイドも同旨：縦方向の柱間隔は車室幅の整数倍（1・2・3台分）、クリアスパン（内部無柱）が経済的なら優先 | | steelconstruction.info（駐車場16.5mロングスパン例、バイパターン 4.5+7+4.5m＝中央車路） |
| GMS等チェーンは什器標準化のため共通スパンを要求することがある | | NDLテキスト |
| 荷捌きスペース 7.7m×3.0m（東京都の例）—§「裏側」のINTERIOR_MODEL_V2と連動 | | NDLテキスト |

階高への効き方（同テキスト＋§2.2からの推論）：
- 商業施設はダクト・配管のため天井懐が事務所より大きく必要。S造（梁せい小）が階高を抑えやすい一因。
- 天井高の目安：改装例で約3m、ロードサイド商業ではクリア約5mの傾向。

### 2.5 マンション：住戸モジュールと柱・壁

| ルール | 根拠の強さ |
|---|---|
| ラーメン架構の柱芯間隔は **6〜9mが標準**、均等スパン（X・Yで等間隔）が理想形 | （一級建築士製図の整理。住戸間口と整合させる） |
| 柱1本あたりの負担面積は **約50㎡程度** を目安に過大にしない | （試験対策の目安値） |
| 壁式では戸境壁・間仕切壁そのものが耐力壁 → 柱は出てこない。住戸プラン（間口×奥行）が構造グリッドを決める | |
| ラーメンでは柱を住戸の隅・戸境ラインに寄せ、居室内に柱型を出さない配置が常套（出た場合は「柱型」として家具配置の制約になる） | |
| PC梁支持など特殊部では柱 800×1000 程度、一般部は低層 約700×700／中高層 約800×800 という整理 | （試験対策的整理） |

### 2.6 梁せい→階高の関係（生成器の計算式）

階高 ＝ 天井高（クリア） ＋ 梁せい ＋ 天井懐（設備） ＋ スラブ厚、で決まる。したがって：

- 同じスパンなら **RCは階高が大きくなりやすく、Sは小さくできる**（§2.2の比の差がそのまま効く）。
- 大スパン化（柱を抜く）すると梁せいが増え、階高アップか天井高ダウンのどちらかで代償を払う（§3）。
- 生成器では「スパン→梁せい→必要階高」を連動させ、外形の階数推定（高さ÷階高）と矛盾しないようにするのが一貫性の肝。

## 3. 柱を「落とせる場所／落とせない場所」

### 3.1 基本原則

| ルール | 根拠の強さ | 出典・補足 |
|---|---|---|
| 柱配置は **平面的に均等なスパン** を原則とし、経済性と力の均等配分を図る | | 農林水産省 系設計指針「柱の配置は、経済性を考慮して、平面的に均等な配置とすることを原則」（https://www.jfa.maff.go.jp/j/gyoko_gyozyo/g_thema/attach/pdf/sekkei_kaitei-111.pdf ） |
| 柱は **各階で上下を一致** させる（柱の通りがずれると力の伝達経路が乱れ応力集中） | | 岐阜県チェックポイント解説（https://www.pref.gifu.lg.jp/uploaded/attachment/39726.pdf ）「柱は均等に配置し、各階の上下柱を一致させる」 |
| 整形な架構（柱位置が揃い、スパンが規則的）は挙動が予測しやすく有利。不整形（抜け柱、極端な長スパン混在、吹抜け周り）は要注意 | | 構造計画解説（https://kenchikusetsubi.tech/articles/kozo-keikaku-kiso ） |
| 柱は平面の **四隅・外周・梁の交点** に置くのが基本。間仕切ライン・区画境界・コア周囲に寄せ、室の中央に出さない | | 同上＋海外構造計画原則（Scribd収録の講義資料は扱い） |
| 短柱（シアスパン比が小さい柱）は原則として設けない | | 文科省『建築構造設計指針』「せん断スパン比1より小さい短柱は原則設けない」。腰壁・たれ壁で短柱化する配置を避ける（沖縄県留意事項） |

### 3.2 用途ごとの「置ける／置けない」

| 場所 | 柱の可否 | 理由・根拠 |
|---|---|---|
| 店舗区画境界・間仕切ライン上 | ◎ 置ける（むしろ置く） | テナント区画と構造グリッドを一致させるのが商業計画の常套 |
| モールの縁（モールと売場の境界ライン） | ◎ 置ける | モール自体は吹抜け・大空間だが、縁のラインは柱列として使える |
| コア（階段・EV・PS）周囲 | ◎ 置ける／耐震壁化も | コア壁は耐震要素としても使える（§4） |
| 駐車場の車路・車室の中央 | × 置けない | 車室モジュール（§2.4）の整数倍グリッドで回避するのが計画の出発点 |
| フードコート・アトリウム・シネマ・体育館等の大空間 | × 原則置けない（抜く） | §3.3の手法で対処 |
| 搬入口・荷捌きの車両動線 | × 置けない | バース前面は無柱が前提（INTERIOR_MODEL_V2のL3ルールと連動） |
| 梁の中央下（空間側に制約がない場合） | ○ 梁せい抑制のためにあえて1本入れることがある | 岐阜県解説「梁下に柱を1本入れることで梁断面を抑えることができる」 |

### 3.3 大空間で柱を抜く手法と代償

| 手法 | 内容 | 代償 | 根拠の強さ |
|---|---|---|---|
| 大梁（梁せい増し） | スパンを飛ばす分、梁せいが比例的に増える（§2.2の比） | 階高アップ or 天井高ダウン。RCでは自重増が連鎖 | |
| PC梁（プレストレスト） | 10〜16m級の無柱空間に典型。せい＝スパンの1/15〜1/12 | コスト高、スリーブ（設備貫通）位置に制限、支持柱の大型化（800×1000級） | （試験対策的整理＋桜井市資料） |
| S大梁／トラス梁 | 最上階の大空間では RC柱＋S大梁（トラス or H形）の混構造が典型 | 鉄骨屋根梁の上には室を置けない（＝最上階限定の手法） | |
| トラス／スペースフレーム／シェル・膜 | 体育館・ホール・アトリウム・駅大屋根など、通常梁の経済範囲を超える無柱空間 | 特注製作が多くコスト敏感。構造が"見える"意匠要素になる | （JISF／構造一般） |
| トランスファー梁（受替梁） | 上階の柱を大梁で受けて下階の柱位置をずらす／落とす | 梁が巨大化、力の流れが複雑化 | |
| 岡立ち柱の禁止 | 長スパン大梁の上に上階の柱を立てる「岡立ち」は構造的に大きな不利 → **原則禁止**。大空間計画はこれを避けるか、明示的な受替構造にする | 大空間の直上に通常フロアを載せる計画が制約される | （設計試験の原則として広く共有） |
| メガ柱（柱の集約） | 少数の巨大柱に集約して間を大きく開ける | 柱1本の負担面積・基礎負担が跳ね上がる | |

生成器への含意：アトリウム・フードコート・シネマの範囲では (1) 内部の柱を消し、(2) 周辺の柱を一段太くし、(3) その階の梁せい（＝階高への反映 or 天井高の減少）を記録し、(4) 直上に柱が立つ場合はトランスファーとして明示する、までをセットにする。

## 4. 耐震要素の配置原則

### 4.1 法・指針レベルの定量指標

| 指標 | 値 | 根拠の強さ |
|---|---|---|
| 層間変形角 | 原則 **1/200** 以下（条件により1/120まで緩和） | 建築基準法（耐震計算ルート） |
| 剛性率 | **0.6以上** | ルート2 |
| 偏心率 | **0.15以下** | ルート2。超える場合はルート3でFes割増 |
| RC/SRC・ルート1の偏心率 | 概ね **0.3以下** を推奨 | 東京都指針 |
| 大地震時の層間変形角の設計目標 | RC 1/200、SRC 1/200、S 1/100 | 東京都指針 表5.1 |

### 4.2 配置の考え方

| ルール | 根拠の強さ | 出典 |
|---|---|---|
| 耐震要素は **平面的・立面的につりあいよく** 配置する。各階の **重心と剛心を各方向でできるだけ近づける**。耐力の分布も平面バランスを取る | | 文科省『建築構造設計指針・同解説』構造計画章（https://www.mext.go.jp/content/20210409-mxt_bousai-100001899_3.pdf ） |
| 立面方向は「支持重量あたりの剛性」を階ごとに均等に近づけ、変形の集中（弱い階）を作らない。上階で耐震要素を急に減らさない | | 同上 |
| 剛心を重心へ寄せる操作：壁の少ない側に壁／ブレースを足す、壁の多い側は壁を減らす・スリットを入れる | | 既存建物耐震補強マニュアル系 |
| 耐震要素は **下階まで連続** させる（途中で切れる壁・ブレースは力の伝達が切れる） | | 同上 |
| 平面の四隅・外周にバランスよく置くとねじれ剛性が上がる | | 構造計画解説（kenchikusetsubi.tech） |
| 短辺方向の偏心は特に避ける | | 耐震補強マニュアル系 |
| 小規模建物の目安：四隅にブレース、短辺5m・長辺8m以下のブロックで考える | （住宅規模の知識ページ） | パナソニック知識ページ |
| ブレースを少数の架構に集中させる案は成立しうる（免震S造の研究）が、内部自由度が下がるトレードオフ | （J-STAGE論文・研究事例） | J-STAGE |

### 4.3 種別ごとの表現（生成器の描き分け）

| 構造 | 耐震要素の典型配置 |
|---|---|
| RCラーメン | コア周囲・外周の一部・戸境壁ラインに **耐震壁** を配置。マンションでは戸境壁と耐震壁が一致しやすい |

## 5. 基礎形式の推論

### 5.1 地耐力による選択（告示の考え方）

国土交通省告示第1347号の解説（日本建築家協会関東甲信越支部の相談解説）：

| 長期許容地耐力 | 基礎形式 |
|---|---|
| 20 kN/㎡ 以下 | **杭基礎** |
| 20超〜30 kN/㎡ | べた基礎 or 杭基礎 |
| 30 kN/㎡ 以上 | 布基礎・べた基礎・杭基礎 のいずれも可 |

出典：https://www.jia-kanto.org/soudan/counseling/592/

### 5.2 実務の選択ロジック（決定軸は3つ）

決定軸：**支持層の深さ／長期許容地耐力／建物の荷重規模**

| 条件 | 推論される基礎 | 根拠の強さ |
|---|---|---|
| 支持層が浅い（〜2m）＋ 地耐力30以上 | 直接基礎。柱荷重が集中する工場・倉庫型は **独立基礎**、低層RC/Sはべた基礎も | |
| 地耐力20〜30（やや軟弱） | RC/S：地盤改良＋べた基礎、または杭。住宅：べた基礎（布基礎は原則不可） | |
| 地耐力20未満（軟弱） | **杭基礎**（軽い建物は地盤改良で代替も） | |
| 支持層の目安：砂礫層 N値30以上／粘土層 N値20以上かつ圧密の恐れなし。良好層が5m以内に現れる範囲が直接基礎の検討域 | （農林水産省系 設計テキスト） | |
| 土木系の経験則：支持層深さ〜2mまで直接基礎、5m以上は杭が一般的 | | |
| 液状化する地層とその上層は原則として支持地盤にできない。杭を液状化層を貫いて支持層まで入れるのが有効な対策 | JIA解説／構造解説 | |
| 一つの建物に異なる基礎形式を混用しない（原則） | 建築基準法第38条関係の解説（要原典確認） | |
| 高さ13m超 or 延床3,000㎡超 かつ 最下階の単位面積荷重100 kN/㎡超 の建物は、基礎底（杭先端）を良好な地盤に到達させるか、構造計算で安全性を証明 | 同上（要原典確認） | |

### 5.3 地盤が「分からない」場合の扱い（生成器の設計指針）

- **個別敷地の地盤は公開情報だけでは確定できない**。実務でもボーリング調査（標準貫入試験）なしに基礎形式は決まらない。これが原則。
- ただし **地域性の事前分布（prior）としての推論は正当**：
- 公開データ源：国土交通省ハザードマップポータル（液状化・浸水）、地形分類図（自然堤防・旧河道・埋立地・台地 等）、地盤情報の公開DB（KuniJiban等）、自治体の地盤・液状化マップ。
- 推論の型：海岸低地・埋立地・旧河道・河川氾濫原 → 支持層が深く液状化リスク高め → 杭基礎の確率を上げる。台地・丘陵（ローム層）→ 支持層が浅く直接基礎（べた／独立）の確率を上げる。
- 生成器の実装方針（推奨）：地盤は「地域priorからサンプルした仮定」として生成し、建物データに `groundAssumption`（推定支持層深さ・液状化リスク・根拠＝地形分類）として明示する。**確定情報として扱わない**。ゲーム側では「地盤調査をしたら想定と違った」というイベントの種にもなる。

## 6. 柱位置・構造が「建て方（施工）」に与える影響

### 6.1 工期モデル（国交省 建築工事適正工期算定プログラムの考え方）

出典：国土交通省『建築工事適正工期算定プログラム』解説（https://www.mlit.go.jp/policy/shingikai/content/001327704.pdf ）

| ルール | 内容 |
|---|---|
| タワークレーン台数 | 基準階面積 **1,200㎡あたり1台**（切上げ）が目安。鉄骨建方時の同時使用は最大2台まで |
| S造の「節」分割 | 地上部の節は **高さ15m以下 かつ 3フロア以下** で分割。1〜2Fで1節、地下は各階1節 |
| RCの工区（打設区画） | 1日の打設量と床面積で決める：ポンプ1台体制で **150㎥以下**、2台で **200㎥以下**、かつ床面積 **300㎡以下**／工区（抽出値。要原典確認） |
| 非RCの工区 | クレーン1台がカバーできる床面積で決める |

生成器への含意：平面が大きい建物ほど「工区分割」と「クレーン台数」が自動的に決まる。柱グリッドが工区境界とずれると施工性が落ちる、という"らしさ"もここから作れる。

| ルール | 根拠の強さ | 出典 |

## 7. 生成器の推論レイヤーへの落とし込み（手順の提案）

上記を生成順序に並べ替えたもの。すべて推論タグ付きで保持すること。

1. **構造種別**：用途×階数×必要スパン → §1の表で決定（商業低層大スパン＝S、マンション〜5F＝壁式RC／6F〜＝RCラーメン、駅上家＝S、等）。
2. **モジュール決定**：商業＝駐車モジュール（車室幅×3→8.5〜9m級）、マンション＝住戸モジュール（間口×奥行、ラーメンなら6〜9m）、駅＝ホーム・軌道モジュール（USE_RULES側）。
3. **柱グリッド**：モジュールの整数倍グリッドを全面に敷き、§3.2の「置けない場所」で柱を消し、「置ける場所」（区画境界・コア周囲・モール縁）に寄せる。上下階一致を維持。
4. **大空間の処理**：フードコート／アトリウム／シネマでは内部柱を消し、周辺柱を太くし、梁せい増を階高 or 天井高に反映。岡立ちを作らない（作る場合はトランスファーとして明示）。
5. **部材寸法の初期値**：§2.1・§2.2の比で柱・大梁・小梁の寸法を出す（RC太く／S細くの描き分け）。
6. **耐震要素**：重心≒剛心になるよう、コア＋外周／複数通りに耐震壁（RC）or ブレース構面（S）を分散配置。下階まで連続。
7. **基礎**：§5.2で形式を決める。地盤は地域prior（地形分類・液状化マップ）から仮定としてサンプルし、`groundAssumption` に根拠付きで記録（確定扱いしない）。
8. **施工属性の導出**：基準階面積→クレーン台数（1,200㎡/台）、S造→節分割（15m・3フロア）、RC→打設工区（ポンプ台数・300㎡上限）とサイクル日数（中層2〜4週／フロア、高層PCa 6〜8日）。ゲームの工程生成にそのまま使える。
