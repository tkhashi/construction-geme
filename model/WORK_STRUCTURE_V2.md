# 工程構造 v2 設計（工種・工区・検査チェーン）

作成：2026-11-08。根拠：hidden_files/source_extracts/work_breakdown_research.md（工種分解調査）、hidden_files/source_extracts/inspection_milestones_research.md（検査・申請調査）。
ユーザーの指摘：①マイルストーン＝各種検査。検査の前に書類作成が必要で、マイルストーンがあっても実際に申し込み・依頼・申請しないといけない。②工種がシンプルすぎる。終わった所から攻める（工区を分けてラップ）。③土工事がない。内装が一括り。設備は電気・衛生・空調・エレベータに分ける。EVは危険作業で、完了すると（養生すれば職人も使えて）上下移動が楽になる。

## 1. 全体構造
- 建物：2階建て。**2工区（A工区・B工区）**。工区ごとに躯体→内装チェーンが流れ、終わった工区から次工種が入る（ラップ）。工区内は直列、工区間は並行可。
- 章の長さ：計画 約24日／工期 26日（目安、バランス調整は実装側）。
- 2D現場：建物が A/B 工区に分かれて見え、工区ごとに色づき（躯体→内装と見た目が変わる）。EVシャフトは中央に1本。

## 2. 工種と作業（工区共通の流れ）
共用（全工区共通・先行）：
1. **土工事**：根切り・山留め（残土搬出は並行）。→ 床付け・地業 → 捨てコン。雨で根切りが崩れる等の土工事らしい揺れはここ。
2. **基礎**：基礎配筋 → 基礎打設（ゲート：基礎の配筋確認）。
工区ごと（A→Bの順に数日ずらして追う）：
3. **躯体**（1F→2F）：墨出し→配筋→型枠→打設→養生。ここに設備の先行仕込み（スリーブ・インサート・打込配管）が同期する＝締切は躯体が決める。
4. **雨仕舞い**（屋根・外壁で水が入らなくなる）→ その工区の内装ロック解除。
5. **内装チェーン**：内装墨出し → LGS下地 → 隠蔽設備（電気配線・空調ダクト/配管・衛生配管）→→ ボード → UB据付（衛生・区画により）→ パテ → 仕上げ（クロス・塗装）→ 床 → 建具・造作 → 器具付け（照明・水栓・吹出口）。
6. **設備は3系統×3段階**で登場する：①躯体先行（スリーブ等、躯体に同期）②隠蔽（内装チェーン内）③器具付け・試験（仕上げ後）。系統：電気／衛生／空調。
- 衛生ゲート：**水圧・満水試験**（隠蔽前、監理者立会い、申請型）。受からないとボードが閉じられない。
- 電気ゲート：**受電**（空調試運転・EV試運転・消防設備の前提）。
- 空調の締め：気密試験→**試運転調整**（受電後、竣工直前に集中）。

### 天井裏・隠蔽段階の内部順序（2026-11-09 追加調査）
根拠：hidden_files/source_extracts/mep_interior_research.md（内装・設備の施工実態調査）。調査由来は（資料）。
- **天井裏の積み上がり順**（資料）：設備3段階のうち「②隠蔽」の内部順序は、インサート確認（インサートは躯体時にスラブへ先付け。吊り元の位置は後から変えられない）→ 吊りボルト・支持材 → **空調ダクト**（天井内で最大の占有物。最初に位置と高さが決まり、他はそれを見て決める）→ ケーブルラック → 電線管・各種配管 → 空調室内機（吊りボルトで**躯体から吊る。天井下地からは絶対に吊らない**）→ 冷媒配管・ドレン配管（ドレンは勾配必須）→ 天井下地 → 天井ボード。ボードを張った時点で天井裏は隠蔽部になり、以降は点検口からしか見られない。原則は「大物・勾配物（ダクト、ドレン）から先に通し、配管・ラックは後から調整する」。これは既存の3段階モデル（先行／隠蔽／器具付け）の隠蔽段階を精密化するもので、枠組みとは矛盾しない。
- **冷媒の順序**（資料）：支持 → ろう付け → 気密試験 → 真空引き → **保温** → 充填。保温は気密試験の後（先に保温すると漏れ箇所が特定できない）。
- **屋上の配線・配管**（資料）：冷媒配管は裸で這わせず、冷媒管ラック／配管ダクトに収め、置き基礎架台（防水を傷つけないコンクリート/樹脂ブロック＋ゴムシート）で支持する（支持間隔1.5m以内）。ケーブルもラック＋架台で支持し、室外機の冷媒は系統ごとにラックへ集約して立下り位置へ向かう。室外機は防振架台の上に据付。
- **衛生**（資料）：給排水はPS（パイプシャフト）の縦管が背骨で、各階で横引き分岐する。雑排水・汚水は勾配と掃除口、通気管の立上げが要る。
- **電気**（資料）：幹線は 受電（キュービクル）→電気室/EPS→縦ラックで各階へ→各階分電盤。天井内はケーブルラック＋電線管＋ボックスから器具へ分岐。

### 実装との差分（2026-11-09 突合せ。ゲームコードは未変更）
本編の実装チェーン（工区チェーン：内装墨出し・LGS → 空調ダクト・冷媒配管 → 衛生配管・埋設 → 電気配管・配線 →［水圧・満水試験］→ 隠蔽前検査 → ボード・天井 ／ 屋上室外機チェーン：架台・基礎 → 揚重 → 据付 → 冷媒配管（ろう付け）→ 気密試験 → 真空乾燥・冷媒充填 → 試運転）と上記の調査順序を突き合わせた差分：
1. **冷媒の「保温」が実装に無い**：実装は ろう付け（rfPipe）→ 気密試験（rfLeak）→ 真空乾燥・冷媒充填（rfVac）で、調査順序の「真空引き → 保温 → 充填」のうち保温ステップが無く、真空引きと充填も1タスクに統合されている。室内側の冷媒配管（工区チェーンの「空調ダクト・冷媒配管」に内包）も同様。
2. **屋上配管の支持の明示が無い**：実装の室外機チェーンに、冷媒管ラック／配管ダクト・置き基礎架台による支持のタスクが無い（冷媒配管タスクへの内包扱い）。架台（rfBase）は室外機本体の架台であり、配管支持とは別物。
3. **室内機のタスク自体が無い**：実装に「室内機」は登場せず、工区チェーンの「空調ダクト・冷媒配管」に内包されている。このため「吊りボルトで躯体から吊る／天井下地からは吊らない」という吊り元の区別も表現されていない。天井裏の吊りボルト・支持材の独立タスクも無い。
4. **ケーブルラックの独立表現が無い**：実装では「電気配管・配線」に内包。順序も、調査の天井裏順（ダクト → ケーブルラック → 配管・電線管）に対し、実装の隠蔽順は 空調 → 衛生 → 電気 で、「電気系ラックが他配管に先行する」点の表現が異なる。ただし衛生（ドレン等の勾配物）を先に通すのは調査の原則（大物・勾配物から先）とも整合するため、大枠の矛盾ではない。
5. **天井下地がボードと統合されている**：実装は「ボード・天井」1タスク。調査では天井下地は隠蔽設備の最終確認の直前段として独立し、その吊り元（インサート→吊りボルト）が設備の吊りと一体で先行する。また先行仕込みの実装タスク名は「スリーブ／埋設」で、インサートの明示が無い（本書 §2-3 の記述にはスリーブ・インサート・打込配管とある）。
6. **衛生のPS縦管が独立していない**：実装は工区ごとの衛生配管のみで、PS縦管（背骨）の先行立上げタスクが無い。
- 一致している点：ダクト（空調）が隠蔽の先頭に来る大枠、水圧・満水試験と隠蔽前検査がボードを閉じる前に置かれる点、気密試験→真空の順序、室外機の架台が屋根防水（ドレン通水確認）の後である点、試運転が受電ゲートの後である点。
7. **エレベータ（全工区共通・1ライン、工区分け不可）**：躯体完了→→レール据付（危険作業：シャフト内高所・重量物）→かご・巻上機→配線・試運転→→養生→**工事用解放**：解放後は上階・内装系作業の効率UP（搬送バフ、例 ×1.25）。代償：養生・美装コスト増、汚損イベント小確率。使わず本設のまま完了検査に臨む選択も可（安全だが遅い）。

### 高所作業車の階別搬入（2026-11-09 ユーザー確定）
- **前提（確定）**：天井裏・天井の作業（設備の隠蔽仕上げ、天井下地、ボード）には高所作業車が要る。高所作業車が入っていない階では、天井まわりの作業は始められない。
- **搬入・搬出（確定）**：高所作業車はラフタークレーンで各階へ揚重搬入・搬出する。搬入はクレーン揚重を占有し、他の揚重・搬送（建方・パネル・資材搬入）と取り合う。
- **締切（確定）**：搬入は外装が閉じる前／開口部からしかできない。当該階の外装（パネル・サッシ・シーリング）が閉じた後に搬入しようとすると、工程が止まる・余計な手間/コストがかかる。搬入タスクは外装閉鎖を期限とする締切的な前後関係を持つ。
- **搬出（確定）**：帯の終わりには「搬出」を置く。搬出忘れは次階の段取りに響く程度の軽い扱いでよい。
- **本編実装**：階ごとに「{f}F 高所作業車 搬入（クレーン揚重・開口部から）」（前工程＝躯体完了、強風停止）を置き、その階の空調ダクト・冷媒配管（隠蔽設備の天井内仕上げの先頭）とボード・天井の前工程にした。当該階の外装4面のシーリングが全て完了した後に搬入が終わると、開口部の一時開放として予算 −3。外装が閉じたのに未搬入の階は、お知らせ・TODO・予兆シグナルで警告し、天井まわり作業は搬入まで止まる。「{f}F 高所作業車 搬出」は当該階の全工区のボード完了が前工程で、引渡し準備の前工程にも接続する（車を階に残したまま引渡しにはならない）。次の階の搬入より後に搬出がずれ込むと二度手間で予算 −1。アイソメでは、クレーンが高所作業車（作業籠付きの台）を階へ吊り上げる様子と、搬入後に階内を移動しながら天井作業する様子を描く。

## 3. 検査マイルストーン＝「書類→申請→実施」のチェーン（最重要の新構造）
マイルストーンは点ではなくチェーン。各検査は3段のタスクを持つ：
- **書類作成**（監督の作業。夜の内業フェーズ等で進める TODO。材料＝工事中にしか生まれない証拠：写真・ミルシート・強度試験結果。証拠が不足していると書類が進まない＝先行債務の一般形）
- **申請・依頼**（プレイヤーの明示アクション。期限：実施希望日の数日前まで。TODO の週/日リストに「あと○日」と出て促す。忘れると検査が実施できず後工程が止まる＝既存の監理者ゲートの一般化）
- **実施**（立会いイベント。当日は作業が一部止まる。指摘→是正→再確認のループ）
検査リスト（章内）：
1. 配筋検査（監理者立会い、各打設前）
2. 中間検査（特定工程：2階床・梁の配筋完了時、法定。合格証まで打設不可）
3. 水圧・満水試験（衛生、隠蔽前）
4. 隠蔽前検査（内装、ボード閉じ前、工区ごと）
5. EV落成検査（工事用解放と完了検査の前提）
6. 消防検査（設置届→消防検査、竣工ゲート）
7. 完了検査（法定。申請は完了後4日以内だが予約は約2週間前から＝事前タスク化）
8. 竣工検査群は **自→監→施→法** の順（社内自主検査→監理者検査→施主検査→法定完了検査）。最後の期間は「工事というより検査と是正の期間」になる。
リードタイムの目安（調査値）：検査予約は10〜14日前、消防の着工届は10日前・設置届は完了後4日以内・使用開始届は7日前、EV仮使用は協議含め約1ヶ月、コンクリート強度確定は材齢28日（ゲーム内では短縮して扱う）。

## 6. 外装レーン（2026-11-08 追加調査：hidden_files/source_extracts/exterior_research.md）
- 外装は工区とは独立の **立面（面）×階レーン** で、鉄骨躯体を追いかける。本物件の主役は ALCパネル：躯体精度確認→金物・墨出し→パネル建込み→サッシ取付→目地シーリング→仕上げ（塗装）→水切り・笠木。吹抜け・ガラス面はカーテンウォール（工場製作→吊込み→目地シール→現場水密試験）。屋根は屋根防水（下地→ドレン仕込み→立上り先行→平場→保護コンクリート→笠木→ドレン通水確認。詳細は下記「屋上工事」節）。
- **雨仕舞いの成立条件＝4点セット**：①外壁パネル取付 ②サッシ取付＋周囲防水（二線防水）③シーリング ④屋根防水。成立した面・階から内装ロック解除（従来の「雨仕舞い」単独タスクはこれに置き換える）。
- 外装ゲート3種：①シーリングの簡易接着性試験（硬化後）②カーテンウォールの層間ふさぎ＝隠蔽前確認（写真対象）＋現場水密試験 ③**足場解体**＝その面の外装完了の宣言。以後の手直しはゴンドラ等で高コスト化する。
- 天候：シーリング・塗装は雨天不可、パネル建込みは強風で揚重不可。外装レーンは天候係数が最も強い。
- 商業施設特有：A工事（施設側：躯体・共用・ファサード）／B工事（テナント負担・指定業者）／C工事（テナント側：店舗内装・サイン）の区分と、区画引渡し立会い検査→テナント工事着工のゲートは、竣工後の展開として別章候補（本章では施設側サイン＝館銘板・大看板のみ外装末尾に置く）。

## 7. 工種の追加と躯体フローの訂正（2026-11-08 ユーザー指摘）
- **仮設足場（鳶）**：外部足場は面ごとに 組立→存置→解体。組立は当該面の外装開始の前提条件、解体は §6 の外装完了ゲートと同一イベントとして扱う。
- **鉄骨建方**：本物件はS造。躯体の主役は RC式の型枠・配筋サイクルではなく鉄骨：工区ごとに 建方（クレーン揚重、強風で停止）→本締め・建入れ直し→デッキプレート→床配筋→コンクリート打設→養生。配筋検査・中間検査のゲートは床配筋・鉄骨まわりに読み替える。型枠・配筋の本格サイクルは基礎・土間に残る。
- **土工（コンクリート打設）**：打設の実行者は土工＋ポンプ圧送。打設タスクは土工の動員力・生コン搬入・天候に連動。
- 職長のキャラクターパラメータと業種傾向は model/FOREMAN_CHARACTERS.md に定義（開始時ランダム生成、業種分布つき）。

## 8. 工程表の階層と「作成プロセス」自体のゲーム化（2026-11-08 ユーザー）
工程表は1枚ではなく階層：全体工程／3ヶ月工程／1ヶ月工程／週間・日次（既存TODOと時計）。工程表タブで粒度を切り替えて見る（全体＝マイルストーンと工種の山、3ヶ月＝工種と手配、1ヶ月＝作業レベル）。
- **全体工程は着工時点で既に出来上がっている**（ゲーム開始時の前提。作成タスクにはしない）。作成がゲーム内タスクになるのは3ヶ月工程と1ヶ月工程（初版作成＋ローリング更新）。所長＋課長が担い、作業量が多く調整が難しいので時間がかかる（リードタイムのあるタスクとして工程とTODOに乗る）。※2026-11-08 ユーザー訂正（初版では全体も作成対象にしていた）。
- **序盤＝土工事フェーズが「段取りの runway」**：土工事は広さに応じてそれなりに施工時間がかかる。その間に先々の工程表作成（3ヶ月・1ヶ月）・業者手配・仮設計画・各種届出を進めておくのが序盤の主作業になる。
- **業者は着工時から全員いるわけではない**：各業者は工程に合わせて入場してくる（土工→鉄骨→…）。全体工程から入場予定日が決まり、3ヶ月工程の確定遅れが手配・入場の質と時期を悪化させる（§8後段の効果接続はこの前提で読む）。初入場時は新規入場者教育がTODOに載る。
- **課長の繁忙度**が作成速度を決める。課長は施工図チェック・見積査定・立会い・会議・トラブル対応でも忙しくなる。課長が忙しいと3ヶ月工程の完成が遅れる。担当者が下書き・資料作りを肩代わりすると速くなるが、担当者の巡回・写真の手が止まる。
- **3ヶ月工程→協力業者の手配に影響**：3ヶ月工程の確定が遅れるほど、業者の手配が遅れ、来る職人の質が落ちることがある（日替わりメンバーの腕の分布が悪化）。ただし同じ現場に来るメインの職人は基本的に変わらない（名簿のコアは固定、変動するのは応援・新規・補充メンバー）。
- **1ヶ月工程は課長＋担当者が作成**：担当者が作り、課長がチェックを返す。課長の繁忙度が低ければチェックの返りが早く、早く出来上がる。1ヶ月工程が早く・正確に出来ていると職人へ適切な指示ができる（段取り効率↑・手戻り/干渉↓）。遅れている/荒いと指示が曖昧になり、干渉・置場事故・手戻りが増える。
- つまり「工程表を作ること」自体が、検査の書類作成と同じく"締切のある内業タスク"であり、所長・課長の時間という資源を取り合う。

## 9. 1日の終わりの儀式（2026-11-08 ユーザー）
- 1日の終わりは「1ヶ月工程表に対する進捗ステータスの確認 → 残業可否の決定」という流れにする。
- 日次レビュー画面：1ヶ月工程（今月の窓）を予実つきで表示する。作業/工区ごとの計画線と実績、遅れ日数、今月末時点の完了見込み、近づくマイルストーン、明日のキー作業。パラメータの今日の変動もここに集約。
- その上で残業を決める：する/しない＋対象（遅れている作業・業者）。判断材料として遅れ・明日のキー作業（打設等）・監督と業者の疲労・予算・翌日の天候を同じ画面で見せる。残業の予測効果（進捗・疲労・予算）は既存方針通り併記。
- 業者側の事情も効く：疲労が高い/協調性が低い職長は残業を渋る・断ることがある（信頼が高いと引き受けやすい）。残業は「命じる」ではなく「成立するかどうか」の要素を持つ。

> **用語訂正（2026-11-08 ユーザー）**：「日次レビュー」という言葉は現場で使わず違和感がある。夕方の活動の実態は (1)今日の進捗確認（予実の把握）(2)明日以降の作業の確認と調整（作業間調整・搬入/検査予定の確認＝明日の段取り）(3)残業の判断 (4)日報の記録であり、名称は「夕礼・明日の段取り」に改める。本書の §9 の「日次レビュー」はこの名称に読み替える。

## 着工時の順序（2026-11-09 ユーザー確定）
工事開始前の準備はこの順で行う：
1. 仮設事務所の設営：コンテナ型の事務所を運搬してきて配置する（建てるのではなく運んで置く）。事務所には水道と電気の引込工事を行う。
2. 仮囲いを作る。
3. 仮設分電盤と電気の引き込みを行う。
4. ここまで終わって工事開始（土工事へ）。
- 仮設事務所のほかに、職人が休憩する詰所、喫煙所、仮設トイレがある。これらも着工後すぐに作る（福利厚生ではなく、現場なら当然設ける仮設の標準設備として序盤に設営する）。
- 土工事にはユンボ（油圧ショベル）による掘削作業がある。

## 施工順序の訂正（2026-11-09 ユーザー指摘＋調査し直し）
アイソメの組み上がりが実務の順序と違う、との指摘を受けて調査し直した。S造の正しい大順序：
着工準備（仮設）→土工事→基礎→鉄骨（工場製作→搬入→建方→建入れ直し→本締め・溶接→デッキプレート→スタッド→スラブ配筋→打設→養生）→外装（防水・外壁）→設備→内装。原則は「下から上へ、外（防水・外装）から内（設備・内装）へ」「雨水が入らなくなってから内装を始める」（イラスト建築生産入門ほか施工管理解説）。
- ゲームのルールとして確定：**躯体（建物全体の鉄骨フレーム＋床スラブ）が完了するまで、設備（躯体先行の打込み：スリーブ・インサート・スラブ打込配管を除く）・外装・内装は開始しない**。§4 のラップ許可のうち「躯体（上階）×内装・設備（下階）」は廃止し、ラップは躯体内部の工区追っかけと、躯体完了後の外装・内装の工区/面ラップに限る。
- 外装足場の組立だけは建方を追って組み上がる（仮設）。外装作業そのものは躯体完了後。
- EV は従来どおり躯体完了後に開始（§2 と整合）。

## 外構工事（2026-11-09 追加調査＋本編実装）
根拠：hidden_files/source_extracts/gaiko_research.md（外構工事調査。日建連『外構工事見積の解説』・施工管理系資料ほか）。以下、調査由来は（資料）、本編ゲームへの実装済み内容は（実装）と明記する。

### 2層構造（資料）
外構は「最後に一括」ではなく2層に分かれる：
1. **先行外構**：本体着手前〜本体と並行。開発工事（造成・擁壁・雨水排水・雨水貯留槽／調整池）は原則として本体着手前に施工し完了検査を受ける。本体工事中も、躯体に影響しない箇所（建物から離れた駐車場の路床・路盤、囲障＝本設フェンス・塀）と、本体埋戻しと並行する埋設配管は先行できる。
2. **本番外構**：**外部足場の解体が着手の起点（上位制約）**。足場が残る建物際（犬走り・建物際土間・植栽）には入れない。外装完了後に本格着手し、内装と並行して進み、竣工検査・引渡しの前に完了が必須（外構が仕上がらなければ引渡しは終わらない）。
- （実装）本編の外構17タスクは本番外構のみを対象とする。先行外構は独立タスク化せず、序盤の土工事・着工準備フェーズに内包した扱い（割り切り。造成・擁壁・貯留槽の個別タスクは無い）。

### 本番外構の標準フローと実装タスク（実装）
起点は **外部足場 全面解体**（面ごとの解体＝§6・§7 の当該面の外装完了宣言。その全面版が本番外構の着手ゲートになる）。以降の流れ（カッコ内は担当）：
測量・墨出し・境界確認（測量・外構）→ 造成・掘削・整地（土工・重機）→ 雨水排水・側溝・桝の布設（土工・排水）→ 給排水の地中埋設配管（衛生）→ 電気地中管路・ハンドホール（電気）→ 路盤築造・縁石の据付（舗装・外構）→ アスファルト舗装（舗装）／コンクリート土間・養生（土工・左官、荷捌き場）→ 区画線・車止め・路面表示（区画線・外構）／フェンス・門扉の本設（外構・金物）／屋外照明の建柱・点灯試験（電気）／自立サインの建込み（サイン・クレーン）／植栽・芝張り（造園）→ 仕上げ清掃・出来形確認（外構）→ 外構完了検査（排水・点灯・出来形、監理者立会い）→ 外構工事完了。
- **鉄則：埋設は舗装より前**（資料）。舗装後に埋設をやると掘り返しになる。実装でも埋設3タスク（排水・給排水・電気管路）は隠蔽扱いで、閉じる前の写真証拠の対象になる（§2 の隠蔽部管理と同じ考え方）。
- **完了の接続**（実装）：外構工事完了は竣工検査群の先頭＝**社内自主検査の前工程**。§3 の 自→監→施→法 の入口に外構完了がぶら下がる。
- 植栽は最後（資料）：重機・資材が動き回る段階で植えると傷むため、舗装・構造物の完了後。実装でも植栽は舗装・土間の後工程。

### ゾーン制と段取りの干渉（資料＋実装）
- **ゾーン制（奥から手前）**：敷地をゾーン分割し、各ゾーンで 埋設→舗装 の順序を守る。ゲートは最後の1か所を搬入用に残し、その周りが最終施工ゾーンになる。**舗装が済んだ面の上は重量車両・大型重機は入れない**（アスファルトは表面50℃以下まで交通開放不可、コンクリート土間は車両開放まで約1週間の養生。仕上げ面に乗れば傷・沈下・汚れの是正が発生する）。実装では、舗装完了後に土間・サイン建込みを残すと効率が落ちる（段取りを外した代償）＋搬入動線を未舗装側へ切り替える判断イベントで表現。
- **終盤の効率低下**（資料）：敷地が狭まる終盤は使える重機が小型化し、同じ工種でも効率・単価が変わる（日建連）。実装では終盤タスク群に効率低下を付けている。
- **仮設との取り合い**（資料）：仮囲い・ゲート・資材置き場・仮設事務所はすべて外構の施工範囲の上に乗っている。撤去/移設の順番と「出入口をどこに最後まで残すか」「仮設引込みをいつ本設に切り替えるか」を外構と同一工程表で決める。本設フェンスを先行させて仮囲い期間を短縮する合理化もある。
- **搬入動線の共有**（資料）：ゲート・構内道路は内装資材搬入・設備試運転車両・外構で共有するリソース。舗装したゾーンから順に重量車両が退出する。
- **天候**（資料）：外構は屋根がなく全工程が天候に晒される。実装でも舗装は雨天停止、サイン建込みは強風停止（揚重）。
- **クリティカルパス化**（資料）：商業施設は開業日が絶対期限で、外構は引渡し直前に集中しやすい。遅れは開業遅延に直結する。

### 業種と重機（資料）
- 業種：外構専門業者（とび・土工を核に一式窓口、商業施設では一次下請として全体を担う例が多い）の下に、測量・土工・舗装・排水/土木・管（給排水）・電気・型枠/鉄筋/コンクリート・左官・金物/フェンス・区画線/路面標示・サイン・造園が工種ごとに入れ替わる。建設業許可に「外構工事」という単独業種はなく、中身ごとに分かれる。ゲームの用語では外構はサブコンではない（協力業者／専門業者。サブコンは電気・機械＝空調・衛生・EVのみ＝FOREMAN_CHARACTERS の確定ルールどおり）。
- 重機：バックホウ（造成・布掘り・植穴の万能機）、ダンプ（残土・砕石・合材運搬）、ブルドーザー／モーターグレーダー（路床・路盤の敷均し・整形）、ロードローラー／タイヤローラー（転圧）、アスファルトフィニッシャー＋乳剤散布車（プライム/タックコート）、コンクリートポンプ車＋生コン車（土間・基礎）、ユニック車（縁石・側溝製品・桝・フェンス材・高木の小運搬＋吊り下ろし）、ラフタークレーン（サインポール建て込み・照明ポール建柱。§クレーン計画ルール＝ラフター＋横引きが原則、と整合）。
- 職長（実装）：新職長「外構（舗装・造園）」を追加済み。パラメータ（腕3・段取り3・協調性3・積極性3・動員力3、（実装）由来）は FOREMAN_CHARACTERS.md §2 に反映済み（2026-11-09）。

## 屋上工事（2026-11-09 追加調査＋本編実装）
根拠：hidden_files/source_extracts/roof_work_research.md（商業施設・陸屋根の屋上工事手順調査。国交省標準仕様書の引用部・避雷の工程連動解説ほか）。調査由来は（資料）、本編実装は（実装）と明記する。不足指摘時の常設手順（RESEARCH_PROCEDURE.md）に基づき、本編で2タスクに圧縮されていた屋根防水を標準フローへ展開した。

### 標準フロー（資料）
屋根スラブ・パラペット（躯体）→ 防水下地（乾燥必須・雨天不可）→ ルーフドレン仕込み・配管接続 → 立上り防水（平場へ150mm以上張掛け）→ 平場防水（ルーフィング2〜3層）→ 保護コンクリート（伸縮目地）→ 笠木（必ず防水の後）→ ドレン通水確認 → 設備基礎 → 機器据付 → 避雷 受雷部 → 手すり・塔屋仕上げ → 屋上完了。

### 本編への反映（実装）
- 従来の roof1（立上り→平場）／roof2（保護層・笠木・散水確認）の2タスクを、下地（roof0）→ドレン仕込み（roofDr、隠蔽部）→立上り→平場（roof1）→保護コンクリート（roof2）→笠木（roofKasa）→ドレン通水確認（roofFlow）→手すり・塔屋仕上げ（roofRail）→屋上完了（roofDone）の9タスクに展開した。
- **天候ゲート**（資料＋実装）：下地と防水本体は rainStop とし、既存の天候影響（雨天は屋外×0.4／防水停止）に載せた。下地の含水率が高いと施工できない＝乾燥確認を下地タスク名に明記。
- **ドレン通水確認はゲート**（実装）：roofFlow を通過するまで、最上階の雨仕舞い成立（gate の前工程を roof2 から roofFlow へ差し替え）にも、室外機の架台・基礎（設備基礎）にも、屋上完了にも進めない。雨仕舞い4点セットの「④屋根防水」はドレン通水確認まで含むものとして扱う。
- **避雷**（資料＋実装）：接地極は基礎段階の先行埋設タスク（grdPole、前工程＝基礎配筋、基礎鉄筋と接続・隠蔽部）として配置。受雷部（lpsRoof、屋上の縁・角／笠木の継目を橋絡）は笠木の後、竣工試験（lpsTest、導通・接地抵抗）は受雷部＋接地極の両方が前工程。屋上完了は roofFlow・roofRail・lpsTest・室外機据付（rfSet）の成立で、社内自主検査の前工程に接続した。
- **機器据付との接続**（実装）：室外機チェーン（既存）の架台・基礎の前工程を保護層（roof2）からドレン通水確認（roofFlow）へ付け替え、調査フローの「設備基礎はドレン確認の後」に合わせた。二重追加はしていない。キュービクルは地上設備のため屋上チェーンには含めない（従来どおり）。
- アイソメ（実装）：屋上面は保護コンクリート完了で防水色（緑）からコンクリート色へ変わり（防水層は隠蔽される）、パラペットの笠木表現は笠木タスクの進捗で付くよう是正した。

## 屋上・屋外設備（2026-11-09 追加調査＋本編実装）
根拠：hidden_files/source_extracts/rooftop_equipment_research.md（屋上・屋外設備の設置手順調査。電気工事会社の施工フロー・給水装置工事基準ほか）。調査由来は（資料）、本編実装は（実装）と明記する。不足指摘時の常設手順（RESEARCH_PROCEDURE.md）に基づき、本編のタスク構造に不足していた3チェーンを追加した。

### キュービクル・受電チェーン（電気＝サブコン）
順序（資料）：高圧受電申請（承認まで1〜3ヶ月・最優先）→ キュービクル発注・製作（受注生産1〜2ヶ月）→ 基礎・引込管路・接地 → クレーン搬入・据付 → 高圧引込・配線接続・接地 → 自主検査（絶縁抵抗・耐圧・保護継電器・接地抵抗）→ 電力会社立会い検査 → 受電開始。
- **受電はゲート**（資料＋実装）：キュービクルが無いと受電できず、受電は内装の電気工事（器具付け・試験）、EV・空調の試運転、消防の連動試験・検査の前提。本編では従来「受電」が単独タスク（前工程＝1F中工区の電気配管のみ）で節目表示に留まっていたため、上記チェーンに置き換え、全工区の器具付け・屋外照明の点灯試験にも受電を前工程として接続し、実ゲート化した。
- 例外規定（実装）：申請・発注は書類・手配系として躯体完了前から先行可（むしろ早期着手が正しい実務）。基礎・据付は躯体完了後。配置は地上の屋外設備スペース（アイソメでも北側設備スペースに基礎→据付で立ち上がる。従来アイソメで屋上に描かれていた「キュービクル」表示は誤りのため室外機のみに是正）。

### 屋上 室外機チェーン（空調＝サブコン）
順序（資料）：架台・基礎 → クレーン揚重で屋上へ → 据付（水平・防振）→ 冷媒配管（ろう付けは窒素ブロー）→ 気密試験（窒素加圧・24時間圧力低下なし）→ 真空乾燥 → 冷媒充填 → 試運転。冷媒配管の三原則＝ドライ・クリーン・タイト。
- 前後関係（実装）：架台は屋根防水の保護層（roof2）＋ドレン通水確認（roofFlow）の後（「屋上工事」節で付け替え）。試運転は受電後でないと不可（受電ゲートの後工程）。空調試運転調整は室外機試運転の完了を前工程に持つ。アイソメの屋上室外機は本チェーン（揚重・据付）の進捗で載る。

### 受水槽チェーン（衛生＝サブコン）
順序（資料）：基礎 → FRPパネルタンク組立・据付 → 給水引込（前面道路の配水管から分岐・埋設）→ 屋内引込 → 槽内清掃・消毒 → 水張り → 水質検査（残留塩素・色度・濁度・臭気）合格 → 給水開始。容量は計画1日最大使用水量の4/10〜6/10が標準。
- 連動（実装）：給水引込の埋設は外構の地中埋設フェーズ（給排水埋設）と連動し、隠蔽部として写真証拠カテゴリ「埋設配管・排水（外構）」の対象に含めた。給水開始は社内自主検査の前工程＋証拠（水質検査合格）として接続。
