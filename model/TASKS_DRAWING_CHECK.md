# TASKS_DRAWING_CHECK.md — 図面チェック業務 詳細モデル

> 調査：`hidden_files/source_extracts/drawing_check_research.md`（出典はそちら）。ここは業務モデルとしての要約（言い換え）。設計図書優先の原則と承認サイクルの構造が芯。

## 本質

図面チェック＝設計図書（「何を作るか」）を現場で「作れる形」に翻訳する過程の検証業務。

**判定基準は常に設計図書であり、施工図ではない。** 監理者の承諾（公共工事では監督職員の「承諾」）を得ても施工者は免責されない。設計図書との食い違いに気づいたら、黙って描き直さず通知して確認を求める手続きが起点になる（民間約款の「発見→通知→確認請求」、疑義は協議のうえ記録に残す＝標準仕様書）。

**承諾の定義**：書面で申し出た事項への書面による了解。**口頭確認は承諾ではない。**

## 図面の階層と「間」を埋める仕事

| 図面 | 作成者 | 役割 |
|---|---|---|
| 設計図（意匠・構造・設備） | 設計者 | 意匠・構造・性能の規定。縮尺1/100〜1/200、材料は一般名称・性能指定で詳細は描かれていない |
| **施工図** | 施工者（元請）。設備分はサブコンが作り元請が取りまとめ | 設計図を「職人が図面だけで作業できる粒度」に具体化（1/30〜1/50、部分詳細1/10〜1/5）。製品・型番・支給区分まで明記。**設計図に不足する情報（下地厚・逃げ寸法・器具の絶対位置）を現地調査と関係者調整で埋める** |
| 製作図 | 専門工事業者・メーカー | 鉄骨・PC版・建具・家具等の工場製作品。施工図承認後・発注前 |
| 承認図 | —（状態を指す語） | 発注・製作の前提として承認を得た図面 |
| 竣工図 | 施工者 | 実施工を反映した最終図面（将来の改修担当者への情報でもある）。引渡し時 |

### 施工図の4系統＋1

| 系統 | 目的 | タイミング |
|---|---|---|
| **総合図** | 意匠・構造・設備を1枚に統合し干渉と整合を潰すハブ図面（※標準仕様書本文にはない語。特記仕様書や着工前打合せで扱いを決める） | 着工前〜施工早期 |
| **躯体図** | 型枠・鉄筋・打設順序・スリーブ位置など躯体工事の指示 | 躯体着手前 |
| **仕上げ図** | 内装・外装・建具の納まり（平面詳細・展開・天井伏が中心） | 躯体後〜仕上げ着手前 |
| **製作図** | 工場製作品。**製作リードタイムが長い部材ほど早期承認が工程の律速** | 施工図承認後 |
| スリーブ図 | 貫通孔の位置・径・補強筋。躯体図と連動 | 躯体図と連動 |

作成・提出・承諾の順序は **総合図→施工図→スリーブ図** が基本。この順序を飛ばすと下流でつじつま合わせが発生し、変更・追加コストの温床になる。

### 役割分担

- **担当者**（作図者）：作図、自己チェック、質疑応答書の起票、修正・再提出
- **課長・先輩→所長**：社内チェック層。赤入れ、疑問点の記録。所長が社内最終確認
- **図面屋**：作図実務の外注先。ただし**整合の横断確認と取りまとめは元請側（所長・施工図担当）の役割**
- **サブコン**：自工種の施工図を作成し総合図調整に参加（自図面単体では成立しても重ねると干渉するのが常態）
- **設計者**：設計意図への回答者。役割は施工図が設計図書に適合するかの「検討・報告・確認」までで、**作図自体はしない**
- **監理者／監督職員**：承諾者

標準仕様書の要求：施工図等は施工に先立ち作成して承諾を受ける／関連工事との納まりを関係者と調整のうえ十分検討する／変更時は報告のうえ再度承諾を受ける。

## チェック観点（9群）

優先度の原則は **「後で直せるかどうか」** —— 躯体・地中埋設・貫通スリーブ・防水下地など後戻りコストの大きい箇所ほど初期に丁寧に見る。

- **(a) 基準と整合**：通り芯・グリッドが各図面に記載され整合しているか（見失うと1箇所のズレが次スパン・次工程へ連鎖）／レベル基準（GL・FL・SL・CH）を最初に確定し全図面で統一／寸法チェーンの合計＝全体寸法／平面・断面・展開・天井伏の寸法とレベルの一致／参照した設計図・関連図の**版が最新か**（変更の反映漏れ）
- **(b) 設計図・仕様書との相違**：特記仕様書の読み落とし（数値は特記が標準仕様書に優先）／質疑で解消済みの疑問点が図面に反映されているか／材料の一般名称・型番・支給区分
- **(c) 取り合い・干渉**：ダクト×梁、配管×鉄筋（特に主筋）、スリーブ×補強筋、耐火被覆・下がり天井／天井裏に**保温厚まで含めて**全部納まるか（平面だけでは見抜けず**要所は断面図で検証**）／耐火・防火区画の貫通位置と処理／梁下設備で居室天井高が法定下限（2.1m）を割らないか
- **(d) 納まり**：建具の有効開口・逃げ寸法と家具・器具の矛盾（新人が抜かしやすい）／下地厚・仕上げ厚込みの壁厚と有効内寸法、目地割付／断熱・防水・通気の層構成の順序、気密・断熱の連続性、水勾配
- **(e) 法規**：確認申請対象の変更を含んでいないか／階段の踏面・蹴上げ等の寸法規定／設備数値の基準例：ドレン勾配は原則1/100以上、スリーブ径は管外径（保温含む）より40mm程度大きく、冷媒管の吊り間隔は管径で変わる
- **(f) 施工性**：勾配が始点・終点のレベルで**数字として成立**するか（図上で成立しない勾配は現場でも絶対に成立しない）／工具・作業姿勢のスペース（図で収まっても工具が入らなければ作れない）／支持・吊り間隔、耐震支持、インサート位置（**スラブ打設前に決める情報**）／機器の搬入経路・分解要否、据付離隔／施工順序の前提も図面に書き込む
- **(g) 数量・材料**：「一般名称＋メーカー・型番＋支給区分」で具体化、継手種別・接続方法まで決まっているか
- **(h) 維持管理性**：ダンパー・弁・機器への**点検口の位置が内装図と整合**し点検スペースがあるか
- **(i) 様式・記録**：レイヤ・線種・縮尺・注記が社内標準／チェック済み図面に**検査者と日付**を残す（「描いた人しか分からない図面」を「会社の図面」にする）

## 進め方

**作図前準備（6項目）**：設計図一式の版数確認／特記・共通仕様書の読み込み／現場条件の実寸確認（支給品・既存構造物は必ず現地実測）／関連工事の工程との連動／変更契約か施工者判断かの判定／監理者の承認プロセス確認。疑問点は着工前に質疑応答書ドラフトで解消する。

**作図（6ステップ）**：読み込み→通り芯・グリッド設定→躯体・設備・仕上げの順（下地から表層へ）作図→寸法・注記→干渉・整合の自己チェック→質疑応答書作成と社内チェック回付。

**4層チェック**：自己チェック（作図者）→社内チェック（先輩→所長、赤入れ）→監理者承認（質疑応答書とセットで提出、押印取得）→配布・版管理。

**承認サイクル（指摘管理）**：提出→確認→指摘回答→再提出→承認・承諾→配布を、**同じ図面番号と改訂番号で追える**ようにする。
- 確認範囲を分ける（図面整合／設計意図／他工種取り合い／点検空間・施工条件）——**誰がどこを見たかを残す**
- 指摘に番号を付け図面位置と対応させる。「要確認」で終わらせず確認したい条件と回答者を明示
- 再提出では指摘ごとに修正内容・箇所（修正しない場合は理由）を回答し、図面修正と回答文の一致を取りまとめ担当が確認
- 判断の記録には対象版・判断者・日付・条件・残件を含める。**未回答を自動承認扱いにしない**、条件付き項目を範囲を超えて使用可と扱わない
- 配布は旧版の切り替え（紙・端末・共有先）まで完了して初めて完了
- 承認件数より重要なのは **未決事項（期限超過・再提出待ち・回答待ち・条件付き）の一覧管理**

**タイミング（工程からの逆算）**——学会の施工図作成ルール研究に整理された実務例：
- スリーブ図の承諾は**スリーブ工事開始の1ヶ月前まで**（躯体図の承諾と合わせての運用も）
- 機械室・便所・PS/DS等は詳細図を作成し**施工開始1ヶ月前までに図面承諾**
- 構造体に関わる先行決定事項は全体の承諾を待たず**「部分承諾」**で先行確定（部分承諾した内容は原則変更を受け付けない）
- 変更受付の締切：構造体に関わる変更は**コンクリート打設1ヶ月前まで**（期限超過は原則受付不可）、軽微な変更は打設2週間前／施工図提出期限の2週間前まで
- **施工図作成工程表**を作る：部位別に図面名称・縮尺を設定し、工事着手日から逆算して承諾期限→申請日・返却日・承諾日・部分承諾日を工事工程と並べて管理する
- **施工図の作成と承諾自体を工程表の1作業として載せ、承諾待ち日数を見込む**（見込まないと承諾待ちで材料発注・手が止まる）

**重ね合わせ（オーバーレイ）と読み方**：
- 平面詳細図の最新版を下敷きに設備図（電気・空調・給排水・ガス・スプリンクラー）を重ね、器具位置と壁・天井の取り合いを確認
- 建築図・設備図・電気図の3図面を透かして重ねる手法でも対応可能（着手2日前までに干渉チェックを実施し全員に周知する運用例あり）
- 読み方：全体を一度に見ず**通り芯で区切られたワンスパンずつ**分解して読む（柱・梁・設備・仕上げの関係を1スパンで理解し横展開）。平面図は必ず断面図・詳細図とセットで立体化して見る
- 設備の納まり検討手順：①制約条件（梁下寸法・天井高・スリーブ位置・防火区画・器具位置＝動かせないもの）を先に集める→②自由度の低い大物（大断面ダクト、勾配のあるドレン）からルートを確保→③混み合う場所は断面図で検証→④施工スペースを残す

**総合図調整会議と質疑**：
- 総合図は関係者会議で全員が同じ図を見て合意し「承認済み総合図」として登録する
- 実務のコツ：早く出す（遅い業者は残った隙間を押し付けられる）／譲れない条件は性能上の理由つきで主張する（理由のある主張は通り、好みの主張は流される）／譲るカード（ルート変更、ダクト断面の扁平化）も持つ／決定は図面に反映し版管理で全員が最新版を持つ（「言った言わない」は版の乱れから生まれる）
- 質疑の正式ルートは**質疑応答書**。口頭確認だけで図面に反映しない。回答は図面への反映日・反映箇所まで記録し証跡として残す
- **「止める」判断**：図面と現場が合っていない、他業種との調整が済んでいない、納まりが不明確なまま進もうとしている場合は、施工図を根拠に「まだ進められない」と止めること自体が手戻り防止になる

## 失敗モード（5つの型）

1. **反映漏れ（工種間の転記欠落）**——代表例がスリーブ抜け・位置ずれ（最頻出かつ不可逆寄り）。構造：設備図に必要なスリーブがあっても**建築側の躯体図・施工図に反映されていなければ**型枠・配筋・打設の段階で抜ける。逆に不要になったスリーブが残ると補修・防水処理が発生。打設後のリカバリ：現状実測→構造設計者へ即時報告（発覚から24時間以内が鉄則とされる例）→リカバリ案→承認→修正工事。標準解はコア抜きだが**鉄筋探査と構造設計者の承認が前提で、無断コア抜きは厳禁**（鉄筋を切ると構造体を傷める。目安：コア径100mm以下・梁端部1/4スパン以内はNG、大径は設計変更・補強で別解）。コストは半日〜1日・数万円/か所、追加コア抜き・開口補修は1か所3万〜10万円増の試算例。予防：スリーブ入れ終了時点で位置・径・種類を確認しスリーブ図にチェック印を付ける**消し込み方式**の全数自主検査と記録保存。
2. **立体化不足（高さ方向の見落とし）**：躯体完成後に「ダクトが梁に当たる」「配管が通らない」が発覚→ルート変更・下がり天井追加で手戻り。天井高を先に確定し後から設備が入らず天井を下げる＝意匠変更への波及。現場判断で配管を下げてドレン勾配が破綻。階高が構造図と施工図で不一致→躯体完成後に天井が納まらない。
3. **基準の食い違い**：通り芯・レベル・版の不一致。図面上で位置が正しくても、墨出し・取付時の基準の取り違え（通り芯からか、仕上げ面からか、躯体面からか）で最終位置がずれる——図面側で「現場で再現できる情報」にしておく必要がある。躯体開口・埋込物（建具開口・設備貫通・点検口・シャフト）の漏れは1つの確認漏れが躯体→設備→内装へ連鎖する。
4. **証跡なし**：口頭確認だけで施工図に反映／先輩図面のコピペで現場条件を未反映／特記仕様書の読み落とし。
5. **不可逆工程への波及＋版管理の混乱**：旧版で施工、確認中の版を施工に使用、「どの改訂か」と「何に使ってよいか」の混同。モデルと施工図の乖離。

## 道具・様式

- **質疑応答書**：No.（連番）／発信日／対象図面（番号・名・版数）／対象箇所（グリッド・部位）／質疑内容／回答希望日（工程から逆算）／回答者（監理者・設計者・発注者）／回答日／回答内容／対応（反映日・反映箇所）。注記に通し番号を振って図面と連動
- **チェックリスト**：社内チェックの観点を標準化し若手も所長も同じ精度でレビュー。設備側は提出前自己検査リスト（勾配成立／干渉／保温代／施工空間／点検性／支持・耐震／貫通と区画／版の整合／承諾段取り）
- **指摘一覧表**：指摘番号／対象（図面番号・改訂）／内容／回答・状態（照会中・再確認待ち・回答待ち、期限付き）。番号は改訂を跨いで引き継ぎ、未完了項目を追跡する
- **施工図リスト／施工図作成工程表**：部位別の図面名称・縮尺、着手日から逆算した申請日・返却日・承諾日・部分承諾日を工事工程と並べて管理
- **図面管理表・版管理ルール**：Rev連番、変更箇所は雲マーク＋Rev番号と変更理由を注記、旧版は「破棄」印を押して保管（消さない）、ファイル名に版数。「どの改訂か」と「何に使ってよいか（状態・判断者・配布先）」を別々に記録し、配布済みファイルの無断置き換えをしない
- **消し込み図**：取付後、図面と照らして位置・サイズ・数量を全数確認し図面自体にチェック印を付けていく方式（自主検査記録として保存）

## 業務モデル化まとめ

- **入力**：設計図書（意匠・構造・設備図＋特記仕様書＋共通仕様書）、現場実寸（支給品・既存構造物・レベル基準）、関連工事の工程、既決の質疑回答、監理者の承認プロセス定義
- **処理**：読み込み・質疑起票→作図（総合図→躯体図/仕上げ図/設備施工図→スリーブ図）→自己チェック→社内チェック（赤入れ）→質疑応答→監理者承諾（一部は部分承諾で先行）→配布・版切り替え。干渉調整は「制約収集→大物優先→断面検証→施工空間確保」の順序制約つき
- **出力**：承認済み施工図（Rev管理）、質疑応答書、指摘一覧（未決事項リスト）、製作図・工場発注のトリガー、現場への作業指示の根拠
- **ゲート条件**：承諾なしに着手しない／構造関連の変更締切（打設1ヶ月前）／部分承諾部分は変更不可
- **QCDSE接続**：Q＝図面間整合・法規・納まり、D＝承諾リードタイムを工程に組み込む前倒し管理、C＝手戻り・是正コストの回避（紙の上で済ませる）、S＝貫通部の構造安全・耐震支持の事前確定
