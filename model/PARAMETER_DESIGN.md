# パラメータ設計：敷地形状×構造×工法への対応（2026-11-08）

## 目的と原則
物件生成（BUILDING_MODEL_SCHEMA）とアイソメ試作の両方が「1つの現場のベタ書き」から抜け出すために、条件を**パラメータの集合**として設計する。原則：

1. **5群に分けて直交させる**：敷地／建物／構造／工法／工程・環境。形状を変えても工法は独立に選べ、工法を変えても形状は壊れない。
2. **入力と派生を分ける**：クレーン種別（高さ50mルール）や推奨工区数のように、他のパラメータから決まるものは入力にせず「派生ルール」として持つ。二重入力は矛盾の源。
3. **組み合わせの整合を検証可能にする**：無効な組み合わせ（例：木造で10階、地下なしで逆打ち）はパラメータ検証ルール（P-rules）で機械的に落とす。建物モデルの V-rules と同じ思想。
4. **各パラメータに「影響先」を明記する**：モデル（形）／工程（作業の列）／表現（アイソメの部材と動き）のどこに効くか。効き先のないパラメータは作らない。
5. 既存資産と接続する：敷地は Schema の Site、建物・グリッドは Building/Grid/Level.footprint（v0.4 のセル集合）と一致させ、ここでは「それらをどう決めるか」の入力側を定義する。

## 第1群：敷地パラメータ（site）
| 名前 | 型・範囲 | 既定 | 影響先 |
|---|---|---|---|
| shapeKind | enum: rectangle / trapezoid / polygon / seeded | rectangle | モデル：Site.polygon の作り方。seeded は PLATEAU/OSM の外形ポリゴンから |
| dims | 間口・奥行 mm（polygon/seeded では外接矩形） | — | モデル |
| rotationDeg | 敷地に対する建物の振れ角（0＝辺平行） | 0 | モデル・表現（方位と日の当たり方） |
| roads | 辺ごと：{幅員, 種別（幹線/生活道路/私道/なし）} | 南=幹線 | モデル・工程：搬入ゲート候補と搬入動線、近隣クレームの出方 |
| neighbors | 辺ごと：住宅／商業／田畑／河川／学校… | — | 工程・表現：クレーム感度、作業時間の制約（学校・住宅は早朝制限） |
| gates | 数と位置（辺＋割合）。未指定なら接道から自動 | 自動 | モデル・工程：搬入計画、クレーン配置候補 |
| ground | 地盤：良好／軟弱／岩盤、地下水位：高／低 | 良好・低 | 工程：杭の要否、山留め・揚水の作業が増える |
| slope | 平坦／傾斜（高低差 mm） | 平坦 | モデル・工程：段差のある足場・搬入 |

## 第2群：建物パラメータ（building）
| 名前 | 型・範囲 | 既定 | 影響先 |
|---|---|---|---|
| use | 商業／事務所／共同住宅／工場・倉庫／病院／学校／駅 | 商業 | 全群の既定値を決める起点（USE_RULES と接続） |
| floorsAbove / floorsBelow | 1〜60 / 0〜3 | 3 / 0 | モデル・工程 |
| floorHeight | mm（階別上書き可） | 用途別（商業5800等） | モデル：Level、階段の整合 |
| footprintKind | rectangle / stepped（雁行）/ L / U（コの字）/ setback / seeded | rectangle | モデル：Level.footprint（セル集合）の作り方。setback は階別縮小率も持つ |
| spanX / spanY | mm（モジュール100単位）＋端数処理：端部吸収／均等割り | 8600/8000 | モデル：Grid axes。駐車場併設なら駐車モジュール（9m級）が支配条件になる |
| coreLayout | center / both-ends / one-side / dispersed | 用途別 | モデル：Core 配置。避難歩行距離から階段の追加が派生する |
| atrium | なし／あり（位置と大きさはグリッドのマス） | なし | モデル・工程：吹抜けまわりの手すり・養生、内装の例外 |
| parking | なし／平面／立体／屋上（併設形態） | なし | モデル・工程：別棟・別工区として生成 |

## 第3群：構造パラメータ（structure）
| 名前 | 型・範囲 | 既定 | 影響先 |
|---|---|---|---|
| frameType | S / RC / SRC / 木造 / 混構造（低層RC＋上部S等は階帯で指定） | S | **工程・表現の根幹**：躯体の作業列と部材が全面的に切り替わる（下表） |
| foundationType | 直接（独立/布/べた） / 杭 | 地盤から派生推奨 | 工程：基礎の作業列（杭打ち・杭頭処理が増える） |
| pileType | 場所打ち / PHC / 鋼管（杭の場合） | 場所打ち | 工程・表現：杭打ち機の種類、騒音・振動の近隣影響 |
| basementMethod | 開削（順打ち） / 逆打ち（地下ありの場合） | 順打ち | 工程：地下の進み方が上下逆になる。逆打ちは RC/SRC のみ（P-rule） |
| retainingType | なし / 親杭横矢板 / SMW / 地中連続壁 | 深さ・地盤から派生 | 工程・表現：山留めの部材と期間 |
| seismicElement | ブレース / 耐力壁 / 免震・制震（概要レベル） | frameType別 | モデル・表現：躯体に現れる部材 |

### frameType で躯体プロセスがどう変わるか（工程テンプレートの切替表）
| | S | RC | SRC | 木造 |
|---|---|---|---|---|
| 柱・梁の実体 | 工場製部材を吊って接合 | 型枠→配筋→打設→養生→脱型のサイクル | 鉄骨建方の後に型枠・配筋・打設が回る | 柱梁は木材（プレカット材を組む） |
| 1フロアの山場 | 建方（節単位） | 打設日（生コン車の列） | 建方と打設の二重 | 建て方と金物・耐力壁 |
| ゲート | 本締め・建入れ直し確認 | **配筋検査→打設**、強度確認（材齢） | 両方 | 構造金物の確認 |
| クレーン | 中（部材が重い） | 小〜中（バケット打設・資材揚重） | 大 | 小 |
| 表現の主役 | クレーンと部材 | 生コン車と型枠の転用 | 両方 | 人の手の組立 |

## 第4群：工法パラメータ（method）
| 名前 | 型・範囲 | 既定 | 影響先 |
|---|---|---|---|
| frameMethod | 在来 / PCa（プレキャスト） / ハーフPCa / ユニット | 在来 | 工程・表現：PCa は「現場加工」が消えて大型部材の吊り込みと目地・接合に変わる。部材は完成品で届く |
| pcaRatio | 0〜1（PCa化の範囲：柱のみ/柱梁/床まで） | 0 | 工程：型枠・配筋の量が減り、揚重量と建方の精度要求が上がる |
| exteriorMethod | ALC / PCaカーテンウォール / 金属パネル / タイル（湿式） / 塗り壁 | ALC | 工程：湿式（タイル・塗り）は天候に弱く養生が要る、乾式はパネル枚数が進捗 |
| interiorMethod | 在来（LGS+ボード） / ユニット（UB・システム天井等） / プレハブ間仕切 | 在来 | 工程・表現：ユニットは「箱が入る」イベントになる |
| mepMethod | 先行配管の範囲、インサート/スリーブ方式、ユニット配管 | 標準 | 工程：設備3段階の先行量 |
| liftingPlan | クレーン台数・種別は**派生**（高さ50mルール＋揚重量）。入力は「常駐/随時」の希望のみ | 派生 | 表現：ラフターの日単位出入り or タワーの常設 |
| tempWorks | 足場形式：枠組 / くさび / 移動式（ローリング） / ゴンドラ（高層の外装） | 枠組 | 工程・表現：足場の部材・組立速度・シートの有無 |

|---|---|---|---|
| zoning | 工区割り：方式（階×方向 / 節 / 棟）と数 | 規模から派生推奨 | 工程・表現：追っかけの単位 |
| lapAllowed | 追っかけ可否と粒度（工区間/室単位） | 可 | 工程：並行度の上限 |
| inspectionProfile | 標準 / 厳格（立会い・中間検査の密度） | 標準 | 工程：検査チェーンの本数とゲートの硬さ |
| weatherProfile | 地域×季節（雨天率・強風率・降雪） | 関東・通年 | 工程：天候イベントの発生と作業別の中止 |

| seed | 生成の乱数種 | — | 全体：同じ条件でも違う物件・違う現場の出来事 |

## パラメータ検証ルール（P-rules、抜粋）
- P1 木造は floorsAbove ≤ 4 かつ高さ ≤ 16m 級（規模の上限）。
- P2 逆打ち（basementMethod=逆打ち）は floorsBelow ≥ 1 かつ frameType ∈ {RC, SRC}。
- P3 PCa（frameMethod=PCa/ハーフPCa）は frameType ∈ {RC, SRC}、かつ揚重の派生クレーン能力が部材重量を満たす。
- P4 高さ > 50m では liftingPlan はタワークレーン派生になり、tempWorks.足場はゴンドラ併用が必須。
- P5 杭（foundationType=杭）は ground=軟弱 で推奨必須、岩盤では原則不可（無駄）。
- P6 seeded（敷地・形状）は元ポリゴンの最低寸法がスパンを満たさない場合、生成器が警告し spanX/spanY を再提案する。
- P7 地下あり＋地下水位=高 では retainingType は SMW/連続壁級が必須（親杭では止水できない）。

## アイソメ試作への接続（実装時の指針）
- 試作側の buildSteel 等の固定関数は「工程テンプレート」の実体に置き換える：テンプレートは frameType×frameMethod で選ばれ、ステージ列・部材種・依存・ゲート・材料3分類（工場製品/現場加工/流動）の対応表を持つ。
- 敷地・形状は Site/footprint パラメータから描画グリッドを生成し、座標ベタ書きを排除する（生成側 generate_building.py の生成物を入力にするのが本線）。
- まずは S×在来（現行）と RC×在来 の2テンプレートで切替を実証し、パラメータ検証 P-rules を入力チェックとして先に効かせる。
