# 用途別ルール v0.1（2026-11-08）— 商業施設／マンション／駅舎・駅ビル

位置づけ：PLAN_GENERATION_STUDY の生成パイプライン（10ステップ）に差し込む用途プロファイル。建物モデルの正は BUILDING_MODEL_SCHEMA v0.2。ルールは「条件→決め方」で書き、検証に落とせるものは用途別追加検証（V-U）として挙げる。数値の区分：＝条文値、＝公的・業界資料や実例で裏の取れた値、＝生成の初期値専用（検証には使わない）。詳細・出典は調査ファイル（hidden_files/source_extracts/use_rules_{commercial,mansion,station}_research.md）に残す。

横断の結論：**用途ごとに「生成の支配条件」が違う**。商業＝駐車モジュールと避難法規、マンション＝住戸モジュールと界壁、駅＝軌道と流動算定。この支配条件を先に固定してから平面を割るのが3用途共通の手順。

## 1. 商業施設

### 1.1 配置・グリッド（ステップ1・2）
- 立地タイプで裏側が反転する：郊外型＝荷捌きは地上裏面＋高床プラットホーム1.0m、駐車は平面＋立体（店舗面積÷17㎡/台級）。都市型・駅ビル＝荷捌きは地下フラット（2t車前提・有効高3.2m）、駐車は地下・別棟に圧縮。
- 搬入口・従業員通用口・ゴミ置場は主出入口と別面に置き、住宅に接する面には向けない。
- **グリッドは駐車モジュールが決める**：直上・直下に駐車場がある場合、スパン＝車室幅×3台＋柱。既定 9.0m（2.5m幅時代）、従来 8〜8.5m。駐車と無関係なら什器モジュール（6.0/7.5/9.0m）で決めてよい。
- 建物奥行（両側店舗＋モール）は 36〜42m が標準レンジで、テナント奥行＋モール幅に分解する。階高は 1F 6.0m前後、上層 5.0〜5.5m を初期値。

### 1.2 骨格（ステップ6の前段）
- モール形式の決定：モール軸長 ≦約150m → ダンベル型（2核直線）。長い・大平面 → ループ型か十字型（4核）。**直線モールが300mを超えたら中間コート（吹抜け）を必須**とする。
- アンカーはモール両端に離して置く（隣接させない）。規模レンジ：GMS 6,600〜16,500㎡、食品スーパー 1,000〜2,500㎡。
- 主モール幅は 8m 標準・6m 下限、副モール 4〜6m。
- 吹抜けは平面中央かモール交点に Shaft（吹抜け）として置く。吹抜け周りのエスカレーターは1層ずつの交差配置に限る（2層一気昇降は吹抜けに面させない）。

### 1.3 テナント割（ステップ6）
- 間口はスパンの整数倍または0.5スパン分割（区画境は芯かスパン中点）。専門店の初期レンジは間口5〜9m×奥行12〜16m。
- 業態別適正面積（カフェ等 65〜165㎡級／ファストファッション・ドラッグストア 330〜990㎡級 等）から区画を合成する。
- 飲食区画は DS に接続できる位置に集約する（排気・給排水）。
- 各テナントに裏口を持たせ、裏側にサービスコリドーを周回させる（幅1.5m以上、主系統2〜3m級）。裏側は「荷捌き→検品→コリドー→貨物EV→各階バックヤード」の閉じた系として作り、客動線と交錯させない。

### 1.4 コア・避難（ステップ4）— 法規から逆算する
- 歩行距離：物販の主たる居室から直通階段まで **30m以下**（令120条）。内装準不燃＋主要構造部が準耐火・不燃なら 40m。重複区間は上限の1/2以下（令121条）。売場のある階は直通階段2以上が無条件（令121条、物販1,500㎡超）。
- 避難階段化は物販で前倒し：3階の売場で避難階段化、5階の売場で特別避難階段1以上（令122条）。客用階段は幅1,400mm・蹴上180mm以下・踏面260mm以上（令23条）。避難階段等の幅合計は最大階床面積100㎡につき60cm以上（令124条）。
- つまり階段の数・位置は意匠で決めず、**歩行距離検証を通るまで自動追加**するのが生成手順。
- 客用縦動線コア（ESC・EV）は約100m間隔（最寄りまで50m以内）を初期配置とし、主入口・アンカー入口に寄せる。

### 1.5 防火区画・サービス諸室（ステップ6・8）
- 面積区画は耐火1,500㎡ごと（令112条）、スプリンクラー全面設置で実質3,000㎡。**物販と飲食は異種用途区画で分ける**。吹抜け・階段・EV・シャフトは竪穴区画（V14と直結）。
- 便所は各階コア隣接・同位置に積む。車椅子使用者用便房は各階1以上、床面積10,000㎡超の階は2箇所以上。
- 防災センターは避難階（1F）、出入口2以上。
- 貨物EVは **2基以上**（かご開口1,400mm・積載2,000kg級）、客用とは別の Core に分ける。
- 荷捌きバース数は簡易式「延床÷3,000」を下限とし、マス 3.0m×7.7m。ゴミ置場は容量式（排出原単位×保管日数÷見かけ比重）で決める。

### 1.6 階別用途の割当（ステップ6）
- 賃料指数（1F=100、2F=80、3F=65、4F=57、5F=43、B1F=75）を「払える賃料」の代理指標として業態をソートする：食品・デイリーは1F端部アンカー（郊外SC）、高粗利・小面積は低層モール沿い、飲食・フードコートは最上階、大型専門店・エンタメは上層か端部。
- 駅ビル条件では「駅直結階」を指数100の基準階に置き換える。

### 1.7 用途別追加検証（V-U商業）
- V-U商1 歩行距離：全居室→直通階段 ≦30m（条件つき生成では40m）、重複区間 ≦上限の1/2。
- V-U商2 面積区画：1区画 ≦1,500㎡（SP全面なら3,000㎡）。物販と飲食が別 Compartment。
- V-U商3 テナント形状：奥行／間口 ≦3。
- V-U商4 最大店舗面積 ≦ 小売面積の80%。
- V-U商5 便房：車椅子使用者用便房が各階1以上（10,000㎡超の階は2以上）。
- V-U商6 防災センター：1Fにあり開口（出入口）が2以上。

### 1.8 既存設定（パークサイドモール）への指摘
生成ルールの検証に照らすと、現行の物件設定は次が引っかかる（変更判断は本編側）：
1. 各階20,000㎡ → 面積区画は最低7区画/階（SP全面・耐火の場合）。施工の9工区とは別軸で Compartment を7以上/階生成する必要がある。
2. 歩行距離30mから逆算した階段数が未定（設定に明記なし）。生成では支配条件として自動追加する想定が要る。
3. 車椅子使用者用便房は各階2箇所以上が目安（設定は数の指定なし）。
4. 貨物EVは実務2基以上が標準で、現行の1基は例外扱いが妥当。
5. エスカレーター2基・客用EV3基は100m間隔の目安に対し不足気味（中央集約として成立させるか、コア追加か）。
6. 整合している点：S造・8〜9mグリッド、階高、中央アトリウム、1F食品／2Fファッション／3F飲食の階構成、荷捌きを主出入口と別面に置く動線分離。

## 2. マンション

### 2.1 形式の決定（ステップ1・6の前段）— ここで住戸モジュールが決まる
- 階数 ≦5・小規模 → 階段室型／片廊下型、構造は壁式RCを候補に（5階以下・軒高20m以下）。
- 階数 6〜14 → 既定は**片廊下型**＋RCラーメン（分譲の実態は片廊下型が約80%）。
- 階数 ≧15 または高さ31m超 → センターコア型／中廊下型／ボイド型（既定はセンターコア）。
- 形式→住戸モジュールの切替：片廊下型＝間口狭・奥行広、センターコア型＝間口広・奥行浅、ボイド型＝中間。
- 複数棟では棟ごとに単棟ルールを適用し、Zone は棟×階で切る。棟配置は日影規制と棟間距離が決める。

### 2.2 グリッドと住戸（ステップ2・6）
- 住戸間口は柱スパンの整数倍（1スパン＝1住戸が既定、ワイドタイプは2スパン）。**界壁はスパン境界（柱芯）に一致**させる。
- 片廊下型ファミリー住戸の間口初期値は 6,000mm、ワイドは 7,000mm以上。専有面積の帯：2LDK 55〜65㎡、3LDK 70〜80㎡、4LDK 75〜90㎡。間口×奥行が帯に収まるよう奥行を調整する。
- 住戸プランの既定テンプレートは「田の字」：バルコニー側＝LDK＋居室、廊下側＝玄関＋水回り。水回りは集約しキッチンはLD隣接。棟端住戸は2面開口型に差し替える。
- 階高の初期値は 3.0m前後（タワーは 3.2m級）、住戸内天井高 2.4〜2.5m。

### 2.3 コア・EV・階段（ステップ4）
- 歩行距離：共同住宅（耐火/準耐火）は玄関から直通階段まで **50m以下**（令120条）。板状棟ではコア（階段＋EV）を両端＋中間に置き、この検証を通す配置にする。
- 6階以上の階がある → 直通階段2以上。15階以上の階 → 特別避難階段（付室またはバルコニー経由）。
- 高さ31m超 → 非常用EV必須。基数は31m超部分の最大階床面積1,500㎡以下で1台、3,000㎡増すごとに+1。
- 一般用EVの基数 ＝ ceil（総戸数÷50）、最低1基。
- 共用廊下幅の生成既定：片廊下 1,500mm、中廊下 1,800mm（法定下限は片側1,200mm／両側居室1,600mm）。

### 2.4 シャフト・壁・床（ステップ4・5）
- **PSは住戸ごとに水回り隣接で1箇所、全階同一位置**に置き、縦連続の Shaft として生成する（モデルの縦連続ルールの代表適用例）。MBは玄関脇・廊下側点検を原則とする。
- 界壁（Wall kind=戸境）：厚さの生成既定 200mm（告示仕様の下限はRC 100mm、実務180〜200mm）。**開口を置かない**。高さは天井裏まで到達（法30条：小屋裏・天井裏まで到達＋遮音構造）。
- スラブ厚の生成既定 200mm（機構基準の等価厚15cm以上）。
- 外廊下側の開口は小さくし掃き出し窓を置かない（実務慣行）。外壁側の開口は採光検証の対象。

### 2.5 バルコニー・防火区画（ステップ5・6）
- バルコニー奥行きの既定 1,800mm、手すり高 1,100mm。隣戸境界に隔板を置き、避難経路幅600mmを確保する。
- 面積区画は Level ごとに 1,500㎡（令112条）。**11階以上の Level は住戸単位（100㎡以内ごと）の高層階区画**を Compartment で表す。階段室・EV昇降路は竪穴区画。
- スプリンクラーは11階以上の階が対象（消防法施行令）→ 該当 Level にフラグを持つ。

### 2.6 共用部・外構（ステップ6・敷地）
- エントランスは1F道路側、管理室を隣接。メールボックスは戸数分。
- 集会室：総戸数 ≧40 で設置、面積 ＝ 20㎡＋0.5㎡×総戸数。
- ゴミ置場：面積 ＝ 0.25㎡×総戸数、搬出動線が住棟出入口と交差しない位置。
- 駐車台数 ＝ 総戸数×駐車率（立地パラメータ：郊外 0.5〜1.0／都市部 0.3）。駐輪は戸数×1.0以上、1区画 600×1,900mm。
- 高さ31m超では防災センターを管理室と一体で生成する。

### 2.7 用途別追加検証（V-Uマンション）
- V-Uマ1 採光：全居室の有効採光面積 ≧ 床面積×1/7（照明50ルクス確保の居室は1/10緩和）。
- V-Uマ2 歩行距離：全住戸 玄関→直通階段 ≦50m（経路長で判定）。
- V-Uマ3 界壁：戸境の Wall に Opening が存在しない。
- V-Uマ4 高さ31m超：非常用EVと防災センターが存在する。
- V-Uマ5 11階以上の Level：スプリンクラー対象フラグと高層階区画（住戸単位）が揃っている。

### 2.8 未確定・追加調査
- 令121条の共同住宅における床面積閾値は出典間で表記が揺れる → ルールに数値で落とす前に条文本体を確認する。
- 排煙（令126条の2）は中廊下型・ボイド型の要点だが未深掘り → 内廊下型をルール化する段階で追加調査。

### 2.9 試験準拠プログラム（令和3年 設計製図試験「集合住宅」）— 2026-11-10 追加
調査の経緯と転用評価は INTERIOR_MODEL_V2 §11、原資料は hidden_files/source_extracts/ikkyu_sekkei_seizu_research.md。令和3年課題（駅近・敷地1,680㎡・地上5階RC・テナント併設の賃貸集合住宅、最低25戸）の要求室表を、共用・管理・設備の「標準セット」の雛形として使う。

| 試験の要求室 | 面積（試験値） | 生成器での扱い |
|---|---|---|
| 住戸A 2LDK／B 1LDK／C 1K | 約75／約50／約25㎡（賃貸の階段） | 未適用（gap）：生成器の住戸面積はセル割当で決まる。分譲寄りの §2.2 の面積帯とは別物として併記するに留める |
| エントランスホール | 適宜（風除室、メール＋宅配ボックス、セキュリティ） | エントランスとして生成。メール/宅配は室内設備扱いで室にしない |
| 管理人室 | 適宜（EHに面して受付カウンター窓） | 「管理室」として生成（名称対応のみ。受付窓の開口までは未表現） |
| 共用室 | 適宜（屋上庭園と直接行き来） | 「集会室」（§2.6：総戸数≧40で設置）が相当 |
| ゴミ保管庫 | 15㎡以上（25戸） | 生成する。面積の考え方は §2.6 の 0.25㎡×総戸数を正とし、試験値（0.6㎡/戸）は小規模での下限の参考。生成はセル粒度（1セル〜） |
| 駐輪場（屋内） | 25台（25戸＝1台/戸） | 未生成（gap）：大規模では屋外・別棟が普通。§2.6 の台数ルール（戸数×1.0）は敷地側の情報として保持 |
| 受水槽室／消火ポンプ室／電気室 | 約25／約15／約10㎡ | 生成する（1F、棟ごと1セット） |
| EV | 9人乗り（トランク付）又は13人乗り×1台以上 | §2.3 の台数ルールが優先。試験は小規模前提 |

スケーリングの注意（試験は25戸級 → 生成対象は数百戸級）：
- 戸数比例で効くもの：ゴミ保管庫の面積、駐輪台数、メール/宅配の個数
- 棟ごと1セットで個数が増えないもの：管理人室、共用室、受水槽室、消火ポンプ室、電気室（面積は規模で育つが、生成はセル粒度のため「1セル＝数十㎡」の粗さを受け入れる）
- 試験に無い大規模固有の要素（防災センター＝§2.6 の高さ31m超ルール、機械式駐車場等）は従来ルール側が正

実装状況（2026-11-10）：パラメトリック／シードとも、1F に ゴミ保管庫・電気室・受水槽室・消火ポンプ室 を追加済み（空き住戸列に割当て、列不足の場合は後ろから省略）。住戸タイプ配分と駐輪場は gap として各モデルの assumptions に明示。

## 3. 駅舎・駅ビル

### 3.0 前提：スキーマ拡張が要る（本節のルールはこの拡張を前提とする）
駅は建物単体で生成できない。次の拡張4点は **BUILDING_MODEL_SCHEMA v0.3 で採用済み**（2026-11-08、検証器の V17〜V20 と駅の例 `building_model_station_example.json` で実証）：
1. **Site に軌道軸**（線路中心線の列）を追加し、駅舎・ホームは軸に相対配置する。
2. **ホームの表現**：専用エンティティは作らず、Slab（ホーム床）＋GenericElement（上屋・ホームドア・待合所）＋Room 相当の空間で表す。ホーム縁端・建築限界は検証側の定数として持つ。
3. **改札内/外ゾーン軸**：Compartment（防火）と直交する、Room を2分割する新軸を新設する。
4. **複数 Building の複合**：駅ビルは別 Building とし、駅舎と接続（連絡通路・共有コンコース）で結ぶ。

### 3.1 形式の決定（ステップ1）
- 線路の縦断位置×両側市街地でほぼ決まる：地平＋両側市街地 → 橋上駅か地下化。地平＋片側のみ → 地上駅。高架 → 高架下／橋上。地下 → 地下駅（B1コンコース/B2ホーム固定、島式1面2線が基本）。
- 軌道中心間隔は在来線 3.6m級／新幹線 4.3m以上を定数として、軌道帯の総幅を先に確定する。
- 駅前広場は最小 2,275㎡を下限に、モード別原単位（バスバース70㎡/バース等）で交通空間＋環境空間を正面側に確保する。自由通路型は両側に分割。

### 3.2 グリッド・構造（ステップ2・3）
- 建物の長手寸法の下限はホーム有効長（＝最長編成長以上）。
- 高架下利用あり → 線路方向スパンは橋脚から逆算し 10m前後（最大15m）を基本モジュールにする。線路上空は無柱で、帯を跨ぐ1スパンとして扱う（柱は帯の両側にのみ落とす）。
- ホーム定数：幅は在来線 島式 中央3m/端部2m・相対式 2m/1.5m、新幹線 島式9m・相対5m。高さは電車専用1,100／併用920／客車760／新幹線1,250mm。**ホーム上の柱・壁は縁端から1.0m以上**にのみ置き、建築限界を侵さない。

### 3.3 縦動線（ステップ4）
- 橋上駅＝橋上コンコースから各ホームへ「階段＋エスカレーター＋EV」のセットをホームごとに配置。地下駅＝B1⇔B2間に階段2箇所以上（2方向避難）＋エスカレーター＋EV経路。
- 昇降設備はホーム全域に均等分散させ、本数・幅は流率で決める：階段は設計流率 3,300人/m・時、エスカレーターは 4,500人/台・時。EVは面ごとに最低1基（円滑化経路）。
- 自由通路は両端にEV各1基必須、幅は規模で 3.5〜5m（小）／5〜8m（中）／8〜10m（大）。

### 3.4 平面計画（ステップ6）— 流動算定が支配条件
- ピーク時1時間乗降人員 P から：改札通路数 N=(1/3600)×[乗車/0.7＋降車/1.0]＋予備1、コンコース面積 ≧ 0.7㎡×同時滞留人員、主要通路幅 ≧ P/3,000。下限を満たすまでコンコースを拡大して再配置する。
- 流動原則：乗車流と降車流を交錯させない。出札・券売機は改札に隣接（滞留スペースを挟む）。改札は改札外/内コンコースの境界に1列。
- ゾーニング：旅客ゾーンと業務ゾーンをセキュリティラインで分け、業務ゾーンは背後（ホーム側・端部）にひとかたまり。**駅事務室は改札に隣接**（監視・精算）、運転事務室はホームごとに1室。水廻りは1箇所に集約。
- バリアフリー：円滑化経路を1本確定し、拡幅改札（80cm以上・目標90cm）とEVをその上に載せる。乗降5,000人/日以上の駅ではバリアフリートイレ必須化。
- 面積構成の目安はコンコース約4割・運輸施設約2割。

### 3.5 駅ナカ・駅ビル・高架下（ステップ6の拡張）
- 規模クラスで段階化：小＝改札外の売店のみ。中＝改札内コンコースの流動線沿いに小型店舗列（通路の有効幅を算定値以下にしない）。大＝改札内の滞留型ゾーン＋駅ビル（別Building、異種用途区画で分離）。
- 高架下は橋脚スパン単位で店舗 Room を帯状に割り付け、駅近傍＝物販・飲食、離れるほど駐車・倉庫へグラデーションさせる。
- 新幹線駅は乗換改札で改札が二重になる定数セット、地下鉄駅は深度と出入口配置が変数になる定数セット、として切り替える。

### 3.6 用途別追加検証（V-U駅）
- V-U駅1 ホーム幅・高・縁端離隔が路線種別の定数表を満たす。
- V-U駅2 ホーム上の柱・壁が縁端1.0m未満にない／建築限界を侵していない。
- V-U駅3 円滑化経路が「出入口→拡幅改札→EV→ホーム」を段差なしで1本以上つながっている。
- V-U駅4 改札内/外ゾーンが全 Room を重なりなく覆い、改札を介さず開口で直結していない。
- V-U駅5 コンコース面積・改札通路数・主要通路幅がピーク人員ベースの下限以上。
- V-U駅6 地下駅ではホーム⇔コンコースの階段が2系統以上。
