# 取り込みキット：施主担当（base_v1n 画風・描き直し版）

作成：2026-11-09（キャラ作りサイドチャット）。本編へ再反映するための検証済み素材一式。
背景：施主担当だけ旧フルキャスト生成系（48×48・縦バー目）の画風で残っていたため、base_v1n 系に描き直した。

## 中身
- `portraits/`：肖像4表情（seshu_normal / smile / worried / angry、384×448、透過PNG）
  - 生成元：`characters/base_v1n/gen_v1n.py` の CHARS['seshu']（base_v1n に7人目として追加）
  - 描法は base_v1n 共通：小さな口・鼻、小さめのハイライト目、首・バストあり
  - 施主固有：栗色（#7a4a2b）の長髪を中央分け＋顔横の房で再現、紺スーツ（#2b3a55、白シャツ、反射帯なし）、ヘルメットなし
- `icon/seshu.png`：顔アイコン（base_v1n の icons と同一生成）
- `walk/`：歩行スプライト12枚（4方向×3フレーム、192×240）
  - 生成元：`characters/gen_walk.py`（全22名共通の歩行様式。施主は 'suit' 分岐でヘルメットなし・反射帯なし・紺スーツに修正済み）
  - 歩行は全キャラ共通様式のため、肖像のような画風差は元々ない
- `sheets/`：検証用一覧（seshu_expressions.png＝肖像4表情、walk_seshu.png＝歩行4方向×3）

## 検証
- 肖像・歩行とも目視確認済み：ヘルメットなし、反射帯なし、紺スーツ、長髪の女性担当者の顔立ち・年齢感を維持。
- 服装ルール（2026-11-09 確定分）と整合：施主は現場の人間ではないので安全帽なし。監督側4名の制服統一・近隣代表の帽子化は別途適用済みで本キットには含まれない。
